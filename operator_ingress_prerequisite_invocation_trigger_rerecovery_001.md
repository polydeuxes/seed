## 4. Exact reachable no-argument console topology

Reachable production is:

```text
seed invoked with no arguments
-> argument dispatch creates an EventLedger
-> persistent console writes and flushes `Seed console: `exit` exits.`
-> console reads one boundary occurrence
   -> EOF: return from console
   -> remove one line ending and compare exact bytes with the process-local exit token
   -> exact match: return from console
   -> otherwise run one operator-ingress attempt
      -> allocate attempt identity
      -> record exact raw material capture
      -> strictly decode under encoding testimony or the UTF-8 fallback
      -> record representation examination
      -> decoder does not produce text:
         -> record an attempt-local stopping occurrence
         -> project state
         -> print representation-boundary feedback
         -> return the attempt view
      -> decoder produces text:
         -> record decoded ingress with meaning Unknown
         -> project state
         -> form addressable material from verified event lineage
         -> return the attempt view
   -> persistent console discards the returned view
   -> repeat
```

The process invocation begins implementation control, not a constitutional
first-contact occurrence. Before interpretation, production captures exact boundary
material and encoding/framing testimony. It records raw capture, representation
examination, and either attempt-local stop or decoded ingress; the projector forms
the attempt view and, on decoder success, exact addressable material. The console
consumes only EOF, the exact process-control token, and the attempt call's return of
control; it discards the projected view. Control returns either to the loop or from
the console to `main`.

No reachable branch forms or presents a closed choice. No responsibility examines
presentation invocation applicability. No response can bind to a presentation,
because no exact presented set, occurrence identity, or token-binding relation is
formed or emitted. The literal exit comparison is process control, not selection of
the Book's local-stop presented alternative.
