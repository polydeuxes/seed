# Alternative-formation testimony and authority Fidelity correction 001

## Scope and corrective result

This report performs one bounded correction of
`alternative_formation_testimony_authority_fidelity_recovery_001.md` after the
complete active entrance recovered by PR 2094. The PR 2091 report remains
historical testimony; this report neither edits it nor reopens PR 2080/2081 or
PR 2084/2085.

The governing correction question is:

> Which PR 2091 findings remain valid after PR 2094, which conclusions or
> recommendations no longer stand, and what is the correct present disposition
> of the proposed application-attributed formation testimony and authority?

The bounded result is **negative for production**. PR 2091 correctly separated
application material, an assertion-bearing representation, formation,
participation, recording, and authority. It also correctly found that the first
current explicit `A represents G` assertion is generated post hoc. PR 2094,
however, recovered an earlier and controlling fact: on the active entrance the
presentation-eligibility return is discarded and the fixed probe is produced
without any consumed consumer-local trigger. No current occurrence identifies a
responsible formation consumer or makes the formation sub-road applicable.

Consequently:

```text
no explicit pre-formation testimony exists
does not imply
add an application-attributed formation-testimony declaration now
```

The declaration proposed by PR 2091 is not presently required. Its recommendation
is **superseded by PR 2094** and was **premature**. Formation authority and an
examiner are conditional coordinates of a formation road *if that road becomes
applicable*, not current missing implementation requirements. No formation
implementation is sufficiently specified.

## 1. Independently verified active entrance

The implementation currently performs the following chronology for successfully
decoded, non-EOF ingress:

```text
decoded non-EOF ingress
then potential-goal-standing examination
then presentation-eligibility examination
then exact eligibility return discarded
then fixed choice set constructed
then probe_produced recorded
then AlternativeSourceRepresentation rows constructed
then alternatives_represented recorded
```

The exact standing `Event` returned by `_examine_potential_goal_standing(...)` is
retained and supplied to `_examine_presentation_eligibility(...)`. In contrast,
the eligibility call is a bare expression: its exact return is neither assigned
nor inspected. `common_grammar_choice_set(presentation_ref)` receives only the
presentation identity, and `probe_produced` carries only ingress lineage. The
later representation helper receives the constructed choice set and a newly
generated representation reference, not eligibility or trigger standing.

Thus chronological adjacency supplies no consumption arrow. On this active road,
no consumed occurrence:

* identifies an exact semantic consumer;
* establishes that the consumer requires interpretation;
* establishes a particular common-grammar dependency;
* examines current availability of that grammar;
* establishes inability caused by unavailability; or
* finds this closed-choice treatment applicable.

The exact interpretation or interpretation-candidate-formation owner remains
`Unknown`. The Book's recognition of a possible responsibility does not prove a
current producer is missing, and the current unconditional production crossing
does not make a later formation road applicable.

## 4. Correction C — three non-equivalent orderings

### 4.1 Current complete execution order

For the active successful-decoding branch, the relevant order is:

```text

-> standing examination (returned Event retained and consumed by eligibility)
-> eligibility examination (returned Event discarded)
-> fixed choice-set construction
-> probe_produced recording                  [earlier crossing]

```

Only the first arrow into eligibility denotes the relevant exact-result
consumption. The remaining `->` marks here denote chronology unless expressly
identified otherwise. In particular, eligibility-to-choice-set and
eligibility-to-probe are not consumption relations.

In this complete order, pre-formation relation testimony is **not the first
missing coordinate**. Before the later assertion is generated, the road has
already crossed into production without a consumed occurrence establishing the
responsible semantic consumer, interpretation requirement, grammar dependency,
availability, causal inability, or treatment applicability.


The exact owner and several relations before the formation boundary remain

> absent coordinate whose present materiality is not established; not the first
> missing coordinate in the whole executable road.**

## 5. Correction D — live result and `Event` type

PR 2091's claim that a future formation boundary “must consume the exact live
eligibility Event” was too specific. The narrower requirement is:

> A responsible consumer must consume the exact responsibly produced result
> under sufficient consumer-local occurrence standing.

The relevant forms must remain distinct:

| Form | Current or possible standing | Limit |
| --- | --- | --- |
| exact live result | The exact result returned from one invoked producer boundary | It is not necessarily durable and need not constitutionally have `Event` type. |
| exact `Event` object | The repository's current in-memory implementation witness returned by the eligibility examiner and appended by `_record(...)` | Object type and identity are implementation choices, not a permanent constitutional interface. |
| observer-held producer-return standing | Direct observation that the exact responsible call returned the exact result, together with sufficient call context | It does not automatically travel to another consumer or survive replay. |
| durable recorded `Event` | Evidence that this ledger recorded the identity, kind, payload, time, and causal coordinates | Recording does not prove every assertion true and does not create consumption. |
| reconstructed `Event` | Recovery of the exact durable record so identity, integrity, and fields can be checked | Reconstruction proves record recovery and compatibility, not independent substantive truth. |
| equivalent artifact | Potentially compatible fields and shape | Equivalence alone does not prove the original producer occurrence or exact result. |

For immediate consumption, the consumer needs evidence that the responsible
producer boundary actually ran and returned the exact result, plus the identities,
result standing, purpose/scope, authority, provenance/evidence, lineage, limits,
conflicts, and `Unknowns` material to its own act. Directly observed call/return
standing can satisfy this without recording if that testimony remains available
to the consumer.

For replay or later consumption, it additionally needs preserved, retrievable
producer-occurrence evidence with stable identity and sufficient exact input,
result, standing, integrity/temporal, lineage, scope, authority, provenance,
limits, conflicts, and `Unknown` coordinates to validate compatibility. A durable
`Event` is the repository's present witness of such preservation, not the only
constitutionally possible interface.

The current eligibility result is an exact `Event`, durably recorded and
projected, but its return is discarded. It is **not consumed by formation**.

## 10. Correction G — superseded recommendation

The PR 2091 recommendation is classified **superseded by PR 2094** and
**premature**. “Superseded” identifies its present disposition; “premature” states
why. It is not constitutionally conflicted: the conditional distinctions about
testimony, authority, formation, participation, and recording remain coherent.
It simply moved from a local absence to production before the complete entrance
had established that the local road was applicable.

No production work should now add:

* an application formation-testimony declaration;
* a formation-authority convention;
* a formation examiner;
* a formation `Event`; or
* a formation projection slot.

Nor does this report prescribe deleting any current artifact. A negative
correction is sufficient because neither addition nor deletion is specified by
the current evidence.
