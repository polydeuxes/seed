# Bounded Locality replay and Standing compression investigation 001

## Question

The declared Measurement runner receives the result of
`read_operator_locality_standing` and calls it current Standing.  That result
contains exact material-acquisition results even where no positive Standing
occurrence has been established for those results.

This report asks:

```text
Does the read establish current Standing for every occurrence it returns?

Or does one runtime object currently combine:

bounded Locality replay
+ separately recorded Standing coordinates?
```

This investigation changes no Book clause, Witness Grammar coordinate, or
runtime physiology.  It does not resolve either Witness gate, positive
assignment Standing, or the order of declared Measurements.


The returned dictionary therefore has a mechanically exact common boundary.
It does not have one common positive constitutional status.

## 6. This also sharpens the order question

The declaration-order investigation found no general law:

```text
one Standing boundary
→ at most one occurrence
```

The local serial rule and the numeric host order entered together.  The
current runner then mutates one carried reconstruction after every append and
uses the new tip as the next assignment's responsible boundary.

Once bounded replay is separated from positive Standing, these questions are
independent:

```text
Which exact occurrences have been appended through boundary B?

Which exact Standing Assertions exist through B?

Which prior Standing boundary warrants assignment A?

Which prior Standing boundary warrants assignment B?
```

One serial append stream answers the first question.  It does not answer the
last three by identity.

Therefore both live possibilities remain:

```text
constitutional dependency
    S0 → A → S1 → B

common responsible boundary with serial preservation
             ┌→ A carrying S0
    S0  ─────┤
             └→ B carrying S0
```

The latter would not make the writes simultaneous.  It would stop append
serialization from becoming constitutional dependency without an exact
relation establishing that dependency.
