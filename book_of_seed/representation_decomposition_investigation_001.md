# Representation decomposition investigation 001

## Question

What irreducible constitutional work does `Representation` perform?

This investigation begins with `C0` and then applies this subtraction test
to every load-bearing active use:

```text
What becomes inexpressible when Representation is removed?
```

The comparison separates:

```text
exact material or result preservation
source and provenance coordinates
Standing boundary reference
Scope / Locality / limits
Carriage
Participation in emission
host rendering or formatting
the already-established generic relation position
```

This report changes no Book clause or runtime physiology.  It deletes no
event kind, result, rule, or test.  The durable events remain exact testimony
to the current implementation.

## Direct finding

No single irreducible `Representation` distinction is established by the
active uses inspected.

The noun currently combines two real kinds of work and one developer-supplied
relation word:

```text
1. one durable result preserving exact source coordinates

2. one exact preservation relation:
   result material preserves exact material of source result

3. the word `represents` placed into a generic relation position
```

The first two occur without populating the generic relation position.  Active
law says so directly:

```text
preserve exact material of source result
does not establish
the relation content
```

The third is not recovered grammar.  The generic relation position already
exists, but its existence does not instantiate a relation for every subject
pair.  A result name, source reference, repeated material, formatting, or host
label cannot add a relation instance.

For sourced material, real work survives subtraction:

```text
exact source result and Yield
↓
one addressable bounded result
├── exact material preserved
├── exact source occurrence reference preserved
├── exact prior boundary preserved
└── Scope / Locality / loss / Unknown preserved where established
```

That work carries no relation instance between these subjects:

```text
bounded result R
source I

no relation instance carried between R and I
```

For `C0`, none of that sourced work is carried:

```text
source occurrence reference = None
exact material = None
empty Standing boundary address = None
C0 subject = unestablished
```

After subtracting the word `Representation`, C0 retains only host-recorded
coordinates about the addressed empty boundary and the host-created Act,
Yield, Locality, and result records.  No established relation connects C0 to
S0.  C0 is therefore no more constitutionally established than exact host
testimony about an addressed empty Standing boundary.

## 1. Representation does not populate the relation position

The repository already recovered an exact relation position:

```text

```

An earlier Representation investigation explicitly refused to fill this
position with `is`, equality, membership, classification, or another English
connective.  This report must not refill it with `represents`.

Current runtime material still carries the implementation coordinate name
`represented_relation` for Candidates and several exact results.  That name
does not create a special constitutional relation.  Its value does not alter
the generic relation physiology.

Active `01.Source.A` makes the separation explicit.  Its exact material rule
is:

```text
Representation exact material
--preserves-->
exact material of source result
```

and it separately creates no relation instance:

```text
no relation instance carried between result and source
```

Thus:

```text

generic relation position
```

No special `represents` relation is recovered or proposed here.  If later
responsible physiology instantiates a relation between two exact subjects,
its content belongs in the existing generic relation position.

What becomes inexpressible without `Representation` here:

```text
nothing about the generic relation position
```

That position was already recovered.

## 3. Exact sourced material

real conservation step:

```text

├── exact material M
├── source occurrence reference I
```

The reader refuses changed material, a changed preservation rule, a missing
source, a source outside the Locality, a corrupted source, or broken source
Yield.  Those are exact and useful boundaries.

The constitutional work is:

```text

```

It is not:


not admit a semantic claim.  It establishes a relation between two exact

```text

```

What becomes inexpressible without `Representation` here:

```text
nothing identified
```

The surviving work can be stated as an exact bounded material-preservation
result with an exact source reference and exact pre-emission occurrence.

## Conclusion

Current evidence supports the curator description:

```text
current Representation container
    one bounded result
    + exact preservation coordinates
    + source and boundary references
    + later emission addressability
```

It does not support:

```text
Representation
= one irreducible constitutional distinction
```

Nor does it support:

```text
Representation of X
→ populated relation content concerning X
```

Neither `is` nor `represents` supplies that content.  No special relation is
retained for either word.

The exact work beneath sourced results and emission must remain preserved and
addressable.  The container noun adds no coordinate found by this
investigation.  C0, having neither source material nor an established
subject, retains only exact host testimony after subtraction.

This report does not authorize deleting the runtime result or renaming its
surviving coordinates.  It establishes the next curation boundary:

```text
do not repair a C0 Representation Responsibility
until the container noun itself has survived decomposition
```
