## 1. Direct finding

The two roads share a useful operational skeleton:

```text
exact prior material
-> rule out later work that cannot answer
-> perform exact local tests
-> preserve added distinctions
-> continue while the rule has another answer
```

They do not enact one exact rule.

```text
source-position continuation
    exact ordered continuity chooses the next coordinate
    complete same-content/difference surfaces establish recurrence

cross-surface observer
    carried material pairs address later projection and row pairs
    one-to-one correspondence constrains every next pair
```

The common skeleton is report-level orientation. Active Seed carries the first
exact rule. Python supplies the second.

## 2. Exact live source-position rule

### 2.1 Initial source-position subjects

The live road begins from every adjacent pair of exact coordinates carried by
one direct position result:

```text
positions i, i + 1
-> Compare their exact material
-> same-content | difference
-> one two-coordinate source-position result
```

No material value chooses the initial pair. Exact consecutive position is the
rule.

### 2.2 Recurrence state

For one coordinate count, the recurrence Measurement groups complete
source-position results by their complete ordered Compare findings.

For three coordinates, one surface might be:

```text
difference
same-content
difference
```

The recurrence subject carries:

```text
coordinate count
complete Compare findings
exact references to every source-position result carrying that surface
count
recurrence only when count > 1
```

The carried state is therefore not a mapping between exact material values.
It is recurrence of a complete same-content/difference relation surface across
multiple exact source-position results.

### 2.3 Reachable next coordinate

For each exact support result of one recurrence finding, the live code permits
only:

```text
next position = prior final position + 1
```

The next coordinate must come from the same direct position result. Reaching
the source boundary gives no next coordinate.

No other later source coordinate is tested. This is the strong live path
discriminator recovered earlier.

### 2.4 Exact extension

When the next coordinate exists, the road records a Compare between that new
coordinate and every prior coordinate. It then records one longer
source-position result carrying:

```text
all prior coordinates
the new consecutive coordinate
all prior Compare results
all new Compare results
the exact prior result reference
```

Crucially, the extension is recorded before Seed knows whether its longer
Compare surface will recur.

```text
next consecutive coordinate exists
-> longer source-position result exists

later recurrence of that longer result
-> a separate Measurement question
```

### 2.5 Stopping

The continuation loop stops when either:

```text
one support path has reached the source boundary

or

the latest coordinate count carries no recurrence finding
```

An exact extension that does not join another recurrent surface remains an
exact source-position result. It is not erased or refused merely because it
does not continue again.

## 3. Exact observer rule

The relation-first observer begins from one frame relation and the exact end
material pairs reached through that relation.

### 3.1 Addressed later subjects

One oriented anchor mapping addresses only projection pairs satisfying:

```text
first projection carries every first anchor material
later projection carries every later anchor material
row counts are equal
coordinate counts are equal
```

Unlike the source-position rule, no material-continuity coordinate supplies
one unique next subject. The relation content itself removes projections that
cannot answer.

### 3.2 Row pairing

For each addressed projection pair, the observer requires one complete
one-to-one row pairing:

```text
every first row receives one later row
one later row answers at most one first row
each carried material pair remains exact
```

If one first row has no answering later row, no coordinate walk begins.

### 3.3 Exact extension

The observer walks each paired row in coordinate order. At each coordinate:

```text
carried first material
    must retain its carried later material

carried later material
    must retain its carried first material

new first material + new later material
    adds one exact pair

one-to-many or many-to-one answer
    stops that walk
```

The carried state changes after each new pair. That changed correspondence
constrains the next coordinate.

### 3.4 Stopping and result

Only a walk that transforms every complete first row into its addressed later
row becomes a continuation finding. A partial walk is not retained as one
smaller continuation result.

The observer stops one proposed walk when:

```text
no complete row pairing answers
one carried pair changes
one-to-many or many-to-one material appears
the complete first material does not transform into the later material
```

## 5. Strongest live counterexample

The current source-position controls use:

```text
a + a
a - a
```

Post-freeze spacing added for reading only.

Both three-coordinate paths carry the same complete Compare surface:

```text
difference
same-content
difference
```

The recurrence Measurement therefore places both exact path results under one
recurrence finding.

The corresponding-material Measurement then retains the actual middle
material separately:

```text
first path middle material     +
second path middle material    -
```

Neither middle material recurs at that corresponding coordinate, and no common
exact three-coordinate material result is produced.

This is lawful under the source-position rule:

```text
same complete relation surface
!= same exact coordinate material
```

The observer rule asks a different question. It constructs and enforces exact
material correspondence across two structural surfaces. Its carried mapping,
not same/difference recurrence alone, determines whether the later coordinate
can answer.

Thus the source-position rule cannot be transferred to the observer merely by
substituting projection subjects for source-position subjects.

## 6. Extension versus acceptance

This distinction is decisive.

### Source-position road

```text
recurring prior path
+ exact next consecutive coordinate
-> record the extended path
-> afterward measure whether extended surfaces recur
```

### Observer road

```text
carried correspondence
+ proposed later pair
-> test correspondence compatibility now
-> retain only if the complete walk answers
```

The live source road uses later recurrence to decide whether another extension
round occurs. It does not treat failure to recur as refusal of the extension
already recorded.

The observer uses mapping compatibility as an admission condition inside the
current walk. It records no partial continuation finding when that condition
fails.

Collapsing these would erase the difference between:

```text
an exact result that has no later recurring continuation

and

a proposed pair that violates the current one-to-one relation
```

## 8. What was recovered

The comparison recovers a durable organization below the two exact rules:

```text

-> address only later subjects that can answer some exact part of it
-> perform the full exact rule
-> add exact result material
-> use that result in a later continuation question
```

This organization explains why both roads avoid enumerating every imaginable
complete structure before testing anything.

It is not yet an active universal Seed rule. Turning it into one would require
choosing which coordinates mean:

```text
prior relation material
can answer
full exact rule
state extension
complete
```

The two audited roads fill those positions differently. Their resemblance
does not establish one interchangeable Responsibility or Act.
