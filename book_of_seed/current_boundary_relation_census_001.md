# Current boundary relation census 001

## Question

Does `current` establish a distinction beyond exact addressability, or is it
prose for an exact coordinate that exists?

This census changes no active Book clause, admission, machine grammar,
runtime occurrence, Act, result, relation, identity, or reader.

## Exact falsifier

The live Applicability road supplies an exact result occurrence `R`. After `R`
is recorded, its exact reader resolves it durably from the Ledger.

Two readings of that same Ledger differ only by their selected boundary:

```text
through B1, an exact occurrence earlier than R
    R is absent from the current Applicability results

through R
    R is present in the current Applicability results
```

Later Compare Act occurrences do not displace `R`; a later reading still
returns it. The result identity, material, provenance, and Locality do not
change across these readings.

Thus exact addressability alone does not establish currentness through an
arbitrary selected boundary.

## Coordinate

`current` is boundary-relative:

```text
exact coordinate occurrence
+ exact Locality
+ selected through-occurrence boundary
+ occurrence at or earlier than that boundary
```

The selected boundary is part of the reading, not a field copied onto every
coordinate. An occurrence later than the selected boundary is not returned
by that reading even though the complete Ledger can address it exactly.

## What `current` does not mean

The active current-coordinate accumulators grow with Locality occurrence
order. This control finds no withdrawal, supersession, latest-value choice,
state transition, or separate Current occurrence.

```text
current coordinate          bounded reading coordinate
latest coordinate           not established
unsuperseded coordinate      not established
Current relation occurrence absent
```

## Finding

```text
same exact result                         durably addressable
through an earlier selected boundary      not current there
through its occurrence or a later one     current there
later occurrence displaces it             no
independent Current occurrence             absent
`current` boundary-relative distinction    survives
```

## Disposition

Keep `current` in active Book admission.

It names whether an exact coordinate is returned by one exact Locality reading
through one selected occurrence boundary. It does not name a mutable state or
an additional occurrence.
