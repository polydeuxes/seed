# Result Boundaries and Movement

## Constitutional subject

The exact coordinates required for comparison of current Standing with a bounded result Assertion, and the separate occurrence required for movement.

## Bounded resolution

Where operator material or established Standing carries one exact result Assertion reference, it requires a Scope and exact Locality relation. That result Assertion carries its own source, Authority, Scope, Locality, limits, conflicts, and Unknown.

A responsible Compare accepts current Standing and that exact result Assertion as input only through their exact applicable input relations. Its result is a bounded distinction Assertion preserving the compared subjects, rule, Authority, Scope, Locality, occurrence, conflicts, limits, and Unknown. The Compare result preserves the exact difference, incompatibility, or Unknown established by its occurrence.

An Act occurrence requires exact coordinates of Responsibility, Act, applicable material, Authority, applicable Assertions, Locality, and occurrence. Available material or one supported coordinate establishes no other coordinate and cannot authorize the Act.

Neither a result Assertion nor a bounded distinction requires another Act. Authorization, movement, Standing revision, new Standing, and Stopping each require their own responsible occurrence. A result Assertion having satisfied Standing within one Scope establishes no completion outside that Scope.

### 04.Compare.A — Bounded comparison of recorded findings

Where current Standing in one Locality carries an earlier and a later exact byte-position-pair Measurement result, the later result carries each earlier exact source occurrence reference and one added occurrence reference, and that occurrence carries one exact input relation, current Standing exposes one bounded Responsibility to determine Applicability and compare complete exact findings. A supplied occurrence preserves provenance to a prior source occurrence. An operator material occurrence preserves its exact acquisition result at prior Standing carrying the earlier Measurement result and source occurrences. The result carries exact Responsibility, input Applicability, Participation relation, Compare Act occurrence, Yield, result, and result Standing references.

The exact comparison rule requires Compare of complete measured content under each finding subject and byte pair. The result preserves findings with the same complete measured content, conflicting findings with the same subject but different measured content, findings of the earlier result, findings of the later result, and Unknown findings. It preserves each exact Measurement result reference, Assertion reference, ordered source occurrence reference, added occurrence, provenance, Scope, Locality, Authority, conflicts, limits, and Unknown.

Each exact comparison input requires its exact input relation. That relation establishes no source relation from the added occurrence to a measured difference, truth, Admission, Applicability for another Act, correction, or movement.

### 04.Compare.B — Comparison of one ordered relation path with recorded pair findings

Where current Standing in one Locality carries one exact ordered relation-path Assertion and one exact recorded pair-finding comparison result, current Standing exposes one bounded Responsibility to determine Applicability and Compare them. Applicability requires the exact source occurrence of the path and added occurrence of the recorded comparison plus complete recorded comparison findings for each pair subject. The result carries exact Responsibility, input relation, Applicability, Participation relation, Compare Act occurrence, Yield, result, and result Standing references.

The result preserves the exact path Assertion reference, recorded comparison result reference, source occurrence, added occurrence, each ordered path role, each exact pair subject, and each exact reference to complete recorded finding content. The comparison cannot revise same-content, conflicting, earlier-result, later-result, or Unknown finding Standing. One pair subject under both inputs establishes no source relation or recurrence. An inapplicable input participates in no comparison and yields no comparison result.

## Important distinctions

- result Assertion != current Standing
- result Assertion != bounded distinction
- bounded distinction != failure
- bounded distinction != Authorization
- a function can perform an Act != the Act is authorized
- Unknown Standing != absent Assertion
- current Standing is different != prior distinction revised
- no movement != lawful Stop

## Counterexamples or failure modes

- Treating operator wording about a desired result as established Standing carried by this Seed.
- Treating one function refusal as proof that no exact Act can occur.
- Treating a difference from a reference Assertion as movement established by identity.
- Treating satisfaction within one Scope as completion beyond that Scope.
