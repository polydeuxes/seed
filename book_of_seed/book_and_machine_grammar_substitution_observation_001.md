# Book and machine-grammar substitution observation 001

## Question

Can the demonstrated material-substitution physiology discriminate joints in
the active Book or active machine grammar after the blind joint observer has
made many exact local split surfaces addressable?

This report changes no Book chapter, witness grammar, runtime, or test. A
disposable observer in `/tmp` performed the calculation and recorded no Seed
occurrences.

This experiment is an observer gauntlet. It is not the ABCDEF fanout
experiment.

## Demonstrated substitution testimony

The historical compiled-format road used five exact implementation functions:

```text
JSON
TOML
XML
Python
plist
```

Its actual physiology was:

```text
measured exact material
↓
insert or remove exact observed material at an exact position
↓
invoke each implementation function before and after the change
↓
Compare exact returned coordinates
↓
recurrence under the same exact mutation coordinates
↓
only then address a later substitution
```

It preserved the source admission population, inserted or removed admission
population, exact mutation position, source and result material lengths, each
implementation-function identity, and the source/result returned coordinate.

The historical tests also establish an important limit on this testimony:

```text
five heterogeneous implementation-function rows
↓
matching later substitution across the complete vector
↓
refused for the demonstrated Book pair population
```

A cloned implementation function with the same behavior does establish the
matching vector. Therefore the historical road did not establish that every
parser must agree on a grammar joint. It established exact recurrence relative
to exact implementation functions and mutation coordinates.

## Blind observer calculation

The observer received no target grammar name, relation name, heading, role,
expected literal, or expected joint.

For each independent source it obtained:

```text
exact observed byte population
exact observed adjacent-pair population
exact observed adjacent-triple population
```

It then:

1. invoked the five demonstrated implementation functions on every exact byte
   and exact adjacent pair;
2. preserved exact admitted material populations grouped by their complete
   returned-coordinate vectors;
3. inserted every exact observed byte into every exact observed pair at each
   exact insertion position;
4. invoked the five functions on each result;
5. grouped results only under the same exact source-admission population,
   inserted-material admission population, and insertion position;
6. separately removed each exact byte role from each observed pair;
7. intersected the resulting recurrence coordinates with triples that actually
   occurred in that exact source.

The observer did not make generated triples into source occurrences. Exact
admission-population references remained present; equal boolean vectors did not
erase the material population that produced them.

## Provenance of the nine-group witness

The remembered nine-group machine surface was located exactly.

Commit `df75bc36` added a machine-grammar object whose base was supplied as:

```text
subject
candidate
Participation_relation
```

It then supplied every directed pair of distinct coordinates:

```text
subject                  → candidate
candidate                → subject
subject                  → Participation_relation
Participation_relation   → subject
candidate                → Participation_relation
Participation_relation   → candidate
```

That gives three exact coordinate groups plus six directed-pair groups.

The proving tests did not derive the base of three from raw material. They:

- resolved `role_distinctions` from the machine grammar;
- required the exact three supplied coordinate names;
- required the exact six supplied directions;
- required reversal closure and distinct endpoints;
- substituted a duplicate direction, removed a pair, or promoted identity to
  Standing and required the machine-witness comparison to refuse the change.

The substitutions were mutation sirens over an already-declared grammar
surface. They demonstrated preservation of the supplied distinction; they did
not discover the three coordinates or six directions.

Commit `f956b6fd` removed `role_distinctions` while restructuring the active
Book around exact relations. The current machine grammar has no such object.
The surviving historical tests that directly resolve it are therefore honest
sirens rather than active discovery testimony.

## Exact distinction

Two historical roads had been compressed together in recollection:

```text
compiled-format substitution
├── changes exact material
├── invokes independent implementation functions
└── discovers recurrence of exact returned coordinates

nine-group role distinction
├── receives three coordinates from machine grammar
├── receives all six directed pairs from machine grammar
└── mutates that declared surface to prove collapse is refused
```

The first road genuinely discovers a behavioral recurrence, but its parser
surface does not discriminate the current Book/grammar joints. The second road
proves an exact supplied grammar matrix, but is not a blind source-discovery
road.

Restoring either road as though it solved the other would inject the answer:

```text
parser recurrence
!=
relation-role occupancy

declared role matrix
!=
recovered role matrix
```

## Stopping boundary

The blind joint observer already made exact bounded split surfaces addressable.
The substitution pass established that the five compiled serialization
functions do not discriminate those surfaces into Seed-native joints.

```text
exact bounded local split surfaces
↓
exact occupant substitutions
↓
five parser source/result coordinates
↓
all 778 machine-grammar triples still recur
↓
STOP
```

The first vacant coordinate remains an independently established result whose
rule bears on the relation anatomy rather than on JSON/TOML/XML/Python/plist
acceptance. The current witness grammar may evaluate a frozen blind result
afterward; supplying its former three-coordinate matrix during discovery would
restore developer-authored occupancy.

This negative result is useful: substitution is not itself the discriminator.
Substitution becomes discriminating only through the exact independent Act
whose result is tested for survival.
