# One-to-one relation extension owner investigation 001

## Boundary

Findings only. This report changes no active Book clause, Witness Grammar
coordinate, runtime road, or test.

`cc808f6c` established:

```text
source-position continuation
!= one-to-one correspondence continuation
```

The two rules share an organization in which carried exact coordinates reduce
which later subjects can answer, but every load-bearing rule coordinate differs.

This investigation asks the narrower next question:

```text
does one active Seed Responsibility already carry
the exact one-to-one relation-extension rule?
```

The audit searches by behavior rather than by a noun. Storage indexes,
identity allocation, dictionary keys, replay caches, and duplicate-record
guards do not become Seed grammar merely because they enforce uniqueness in
Python or SQLite.

## 1. Exact rule being sought

The cross-surface observer carries one oriented relation made of exact
first-to-second material pairs. Its continuation rule requires all of these
coordinates together:

```text
1. one carried first subject retains one exact carried second subject

2. one carried second subject retains one exact carried first subject

3. one proposed pair is tested against every carried pair

4. a one-to-many or many-to-one conflict stops that proposed walk immediately

5. one compatible pair is added to the relation carried into the next test

6. one exact completeness boundary determines whether the complete
   first material transforms into the complete second material
```

This is stronger than any one of:

```text
one exact pair
distinct subjects
no duplicate record
one Act occurrence cannot Yield twice
one complete mapping produced all at once
```

The sought owner must carry the complete rule, not merely one compatible
property.

## 2. Active relation grammar does not impose multiplicity

Active `01.Standing.D` requires each exact relation to carry its exact subjects
and responsible occurrence. `01.Standing.E` requires one relation Assertion to
carry:

```text
first subject
exact relation content
second subject
```

`06.Locality.A`, `02.Acts.A` Yield, Support, Participation, Movement, and the
other live relation families instantiate exact two-subject relations under
their own rules.

That exactness does not establish:

```text
same first subject cannot enter another relation occurrence
same second subject cannot enter another relation occurrence
```

Two exact relation occurrences may share one subject unless one family-local
rule says otherwise. Active Book and Witness Grammar contain no one-to-one,
one-to-many, many-to-one, injective, or bijective relation rule.

Therefore generic relation anatomy supplies the two positions but not the
observer's multiplicity rule.

## 3. Occurrence-position Measurement is the closest complete account

`seed_runtime/occurrence_position_measurement.py` establishes every occurrence
position within one exact Locality and append boundary.

Its result carries exact Assertions of this form:

```text
subject: exact occurrence
content: exact source-order position
boundary: exact completeness boundary
```

The finding constructor requires positions `0..n-1` in order and refuses one
occurrence identity appearing twice. The result reader checks the complete
finding against the ledger through the exact boundary. Changed, missing,
reordered, duplicated, and substituted Assertions are refused.

This gives one complete occurrence-to-position account with unique occurrence
subjects and unique ordered positions. It does not enact relation extension:

```text
complete boundary
-> enumerate every occurrence and its position
-> one complete Measurement finding
```

There is no prior carried occurrence-position relation, no proposed next pair,
and no compatibility decision against previously accepted pairs. One accepted
pair does not become the condition for admitting the next pair. The complete
boundary determines all pairs before the result is recorded.

So this road establishes a specialized complete Measurement. It does not own
the observer's incremental one-to-one rule.

## 4. Recorded-pair Compare checks finished inputs

`comparison_of_recorded_byte_pair_measurements._comparison_of_findings()`
indexes each input finding by:

```text
exact result
exact recorded byte pair
```

It refuses either complete input if that input repeats one finding subject.
It then compares matching subjects and records:

```text
same content
conflicting content
earlier-only subject
later-only subject
```

This is a static Compare over two complete inputs. The uniqueness check says
that one input result cannot repeat one of its own finding subjects. It does
not establish a first-to-second relation, test a proposed pair against a
carried correspondence, or add an accepted pair for another test.

The dictionaries accelerate lookup. They are not the result's grammar.

## 5. Shared-position Measurement composes one fixed path

`measurement_of_shared_position_of_byte_pair_occurrences.py` requires:

```text
first pair relation's second position
=
second pair relation's first position
```

It refuses the same position Assertion occupying both input roles and requires
the same source occurrence, Locality, and completeness boundary. Its result
preserves one exact two-relation path through one shared position.

This road composes two fixed relation Assertions. It neither grows a mapping
nor imposes first-to-second and second-to-first uniqueness across a carried
pair set. A successful shared-position result is not used to admit a proposed
third mapping pair.

## 6. Yield carries one directed relation, not a correspondence

Active Yield has the exact anatomy:

```text
Act occurrence --Yield--> result
```

Family-local recorders commonly refuse a second result for one exact Act
occurrence. That establishes one directional restriction for that Act
occurrence.

It does not establish the reverse restriction:

```text
one result cannot be the result of another Act occurrence
```

Nor does one Yield relation become a growing pair set against which another
proposed Yield pair is tested. Yield therefore supplies neither the complete
one-to-one rule nor its continuation.

## 7. Locality, Movement, Support, and Participation remain exact local relations

These relation families each carry exact subjects and their own responsible
occurrence. Some roads also require distinct input roles or exact source and
destination coordinates.

None of the active clauses says:

```text
one first subject has at most one second subject across this relation family
one second subject has at most one first subject across this relation family
```

None carries an accepted relation pair forward as the condition for testing a
later proposed pair. Their exact local relation occurrences therefore cannot
be used as testimony for the observer's rule.

## 8. Exact-material collision refusal is storage mechanics

The ledger's private exact-material store addresses bytes by their digest. It
reuses one private reference for the same bytes and refuses a digest collision
that would address different bytes.

This has a superficial first-to-second uniqueness shape:

```text
private storage reference -> exact bytes
```

It is not a Seed Responsibility, Act, relation occurrence, or result carried
in current Standing. The pair is fixed by the digest operation; it is not
admitted by a growing relation rule. It therefore cannot own one-to-one
correspondence extension.

Promoting this storage guard would repeat the error of treating a durable
implementation discriminator as grammar.

## 9. Candidate does not supply the rule

Active `01.Source.E.1` remains conditional:

```text
one exact Candidate rule
+ one exact subject boundary
+ every exact subject required by that rule
-> complete Candidate production under that rule
```

The Candidate Act establishes neither the rule nor the subject boundary.
Candidate therefore cannot turn enumerable material pairs into required
one-to-one relation work. The removed unary and ordered-pair rules remain
retired.

## 10. Direct disposition

No active Responsibility or Act carries the complete one-to-one
relation-extension rule.

The audit recovers useful partial distinctions, but they remain owned by
different exact roads:

| Active road | Exact distinction | Missing from the sought rule |
| --- | --- | --- |
| relation Assertion | exact first, relation content, second | multiplicity and extension |
| occurrence-position Measurement | complete occurrence-to-position account | carried prior relation and incremental compatibility |
| recorded-pair Compare | unique finding subject within each complete input | first-to-second relation extension |
| shared-position Measurement | one exact composable two-edge path | bidirectional uniqueness and growing pair set |
| Yield | exact Act-occurrence-to-result relation; family-local single Yield | reverse uniqueness and pair-set continuation |
| path discrimination | exact next consecutive source coordinate | one-to-one material compatibility |

The exact vacancy is therefore not `syntax`, `language`, `learning`, or one
universal continuation Act. It is this smaller family-local rule:

```text
exact carried first-to-second relation
+ one exact proposed first-and-second pair

-> compare the proposal with every carried pair

same first + changed second       -> conflicting
changed first + same second       -> conflicting
same exact carried pair           -> compatible without extension
new first + new second            -> compatible extension

compatible extension
-> one result carrying the enlarged exact relation

exact completeness boundary
-> complete | incomplete | conflicting | Unknown
```

This report does not warrant that rule. It only locates the absent physiology
precisely.

## 11. What remains separate

Even if this exact rule were later recovered, two prior questions would remain:

```text

what clause-local condition makes one Responsibility carrying
this rule and those subjects a branch of current Standing?
```

The observer's useful consequence cannot answer either question backward.

The smallest next investigation is historical and comparative:

```text

under another exact relation family,

```

Until that relation is recovered, the cross-surface observer remains a
disposable demonstration of what such physiology could do, not its warrant.
