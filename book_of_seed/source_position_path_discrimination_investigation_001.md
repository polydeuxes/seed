# Source-position path discrimination investigation 001

## Boundary

Findings only. No Book, machine grammar, or runtime change.

This investigation corrects two assumptions left open by `5083f3c3`:

```text
acquisition identity is provenance
!=
acquisition identity is a grammar grouping

all possible paths must be recorded before discrimination
!=
one exact path can address only material capable of continuing it
```

It recovers the old path-discrimination mechanism, audits the live
source-position road for the same physiology, and measures the same ordered
material under three acquisition layouts.

## 1. Recovered discrimination physiology

Commit `706731f6` removed a prohibitive scan from an earlier adjacent-pair
Measurement. One already-supplied pair and one already-supplied form carried
exact keys. The operation inverted those keys once and visited only recorded
occurrences carrying material capable of answering that form.

Two distinctions were explicit:

```text
an occurrence carries an addressing key
!=
the occurrence satisfies the exact occupant test

two subjects share one addressing key
!=
the subjects have an established relation
```

The normal exact test remained after addressing. The index changed which
occurrences were read, not what the Measurement could establish.

That code is retired and its vocabulary is not restored here. The durable
physiology is:

```text
exact addressed work
-> exact carried coordinates rule out material that cannot answer
-> read only material that can answer
-> perform the unchanged exact test
```

It does not explain why the work was owed. The pair and form were already
supplied.

## 2. The live source-position road already transfers it

One live recurrence finding carries exact references to only the producing
source-position results that share its complete Compare surface. Each
producing result carries:

```text
one exact material-acquisition result reference
exact consecutive source-position coordinates
the exact final coordinate
the complete prior Compare findings
the prior source-position result reference
```

`_extend_recurrent_source_positions` reads only those referenced results. For
each one, exact consecutiveness permits only:

```text
next position = final position + 1
```

It then performs the normal Compare between the new coordinate and every
prior coordinate. Reachability does not establish the new Compare result or
later recurrence.

Thus the path-discrimination transfer is already live:

```text
exact recurrence finding
-> only its exact producing paths
-> only the next consecutive coordinate of each path
-> complete exact Compare
-> later recurrence Measurement
```

No delimiter or source division is needed for that continuation.

## 4. Acquisition packaging remains load-bearing

The observer preserves the exact same 262 bytes in the exact same order and
changes only how those bytes arrive:

```text
layout                         acquisition count  distinct exact-material results
one acquisition               1                  143
four acquisitions             4                  153
seventeen-byte acquisitions   16                 8
```

The acquisition edges cause real low-level differences: no active relation
states that the final position of one acquisition is consecutive with the
first position of the next. Those cross-edge paths must not be invented.

The effect is not confined to paths crossing an edge. The current recurrence
Measurement groups results only when they carry the same
`direct_position_result_occurrence`. Results on opposite sides of an
acquisition edge never share one recurrence finding. That changes complete
support for interior paths and changes later exact-material contraction.

Thus one coordinate currently performs two jobs:

```text
direct material-acquisition result reference
-> exact provenance of each source coordinate

direct material-acquisition result reference
-> eligibility boundary for recurrence support
```

The first job is exact. The second makes caller packaging influence later
grammar work.

Interweaving material changes its exact order and therefore changes real
adjacency. Equal low-level findings are not required for that control. A later
higher relation would have to be recovered across those changed local paths;
source identity cannot supply that relation.

## 5. Why a global index is not the repair

The complete Compare surface could mechanically index results across current
Standing without using acquisition identity. That would reproduce the old
addressing optimization:

```text
surface -> results capable of answering a recurrence query
```

But the old recovery already supplies the refusal:

```text
sharing an index key
!=
an established relation
```

Active Compare requires exact subjects and an exact rule already carried by
its Responsibility. Active Measurement likewise begins with one declared
rule. No active clause found here requires recurrence Measurement across all
exact path results merely because their surfaces match.

An index could make such work cheap after it is owed. It cannot make the work
owed.

## 6. Exact unresolved boundary

Two crossings remain distinct:

```text
acquisition edge
-> exact continuity into another acquisition
```

requires a positive relation if the material is truly continuous. Acquisition
order alone does not establish it.

Separately:

```text
exact path results already carried in current Standing
-> recurrence or Compare work across acquisition provenance
```

does not require adjacency, but it does require one exact rule and
Responsibility. No active clause found in this audit supplies them from shared
surface coordinates alone.

The path discriminator is therefore not missing. The exact missing crossing
is the responsibility-bearing relation that would lawfully apply it beyond
one acquisition result.
