# Responsibility Assignment decomposition investigation 001

## Question

What irreducible constitutional work does `Responsibility assignment` perform?

This investigation tests every load-bearing use of Assignment by subtraction.
For each use it asks:

```text
What becomes inexpressible when Assignment is removed?
```

The comparison uses already-established coordinates:

```text
Standing
Responsibility
responsible boundary
subject
exact Act
Authority
Evidence
Scope
Locality
limits
occurrence
Unknown
```

This report removes or implements nothing.  Runtime assignment event kinds are
testimony to current implementation; their existence is not Evidence that
Assignment is an irreducible constitutional distinction.

## Direct finding

No current use requires Assignment as a separate constitutional subject.

Current Assignment combines five different jobs:

```text
1. active Book clause declares one exact Responsibility
2. exact subject and boundary make that Responsibility exact
3. one durable record serializes the Responsibility coordinates
4. later Acts cite that record to prove Responsibility preceded the Act
5. results preserve the same reference as lineage
```

Each job remains expressible without an Assignment object:

```text
current Standing
↓
exact Responsibility R
├── responsible boundary B
├── subject S
├── exact Act X
├── Evidence E
├── Authority Q
├── Scope / Locality
├── limits / Unknown
└── exact durable reference where required
```

The necessary refusal is:

```text
Responsibility R must be exact and current before Act X
```

That distinction is real.  It does not require:

```text
an Assertion A that B is assigned R
↓
Standing(A)
↓
read R
```

No inspected event records the physiology expected of a genuine assignment:

```text
assigner
assignee
Responsibility before assignment
Assignment Act
Assignment occurrence
Authority to assign
Evidence of assignment
changed Responsibility relation as result
```

The current events instead record exact Responsibility coordinates.  Their
established work is implementation serialization and one durable occurrence
reference for those coordinates.  That work establishes neither a
constitutional Representation nor an Assignment Act or Assignment Assertion
by identity.

## 3. Exact subject-specific Responsibility

The strongest apparent work is the crossing from one general Book declaration
to one exact subject:

```text
declared Measurement Responsibility
+ exact material subject S at boundary B
↓
subject-specific runtime record
```

That crossing is real.  The record must preserve which exact Responsibility,
subject, boundary, Authority, Evidence, Scope, limits, and Unknown apply.

It does not follow that the crossing is Assignment.

An exact Responsibility is not one general label.  Its own required branches
already make it subject-specific and boundary-specific:

```text
R(subject=S, boundary=B, Act=X, Evidence=E, Authority=Q, Scope=C, ...)
```

Recording those coordinates distinguishes one exact `R`.  Calling the record
an assignment does not add an assigner, assignee, relation, Act, occurrence, or
result.

The exact work that survives removal is:

```text
one exact Responsibility instance is addressable
and preserves every required coordinate
```

That may require its own durable Representation or an occurrence that carries
`R`.  This investigation does not name that future representation.  It only
finds that `Assignment` is not required to express the distinction.

What becomes inexpressible without Assignment here:

```text
nothing, provided exact R remains independently addressable
```

## 4. Separation from the governed Act

Assignment events entered the runtime during a useful decompression.  Earlier
roads put Responsibility-like material directly beside Act Evidence.  The new
events established a durable earlier position and forced the Act to cite it.

That refusal must remain:

```text
Responsibility coordinates
!= Act Evidence
!= Act occurrence
```

Deleting the Assignment concept must not restore:

```text
host calls Act
↓
Act Evidence contains a Responsibility string
↓
therefore Responsibility existed before the Act
```

The actual requirement is smaller and stronger:

```text
current Standing carries exact Responsibility R
before Act X occurs

Act X preserves an exact reference to R
```

The earlier durable reference can address `R` directly.  It need not address
an Assertion that `R` was assigned.

What becomes inexpressible without Assignment here:

```text
nothing, provided R remains exact, prior, current, and referenced by X
```

## 8. Assignment Standing

The strongest sign that Assignment is artificial is the universal absence
found by the assignment-clause inventory:

```text
assignment occurrences                    recorded
positive Standing for assignments         absent on every implemented road
```

The active Standing source then requires:

```text
A = Assignment Assertion
↓
support-relation Assertion S_A
↓
Standing(S_A)
↓
Standing(A)
↓
read Responsibility R
```

The support Assertion creates an unbounded recursion because its own support
relation is required to have Standing.

Removing the reified Assignment subject removes this particular recursion:

```text
current Standing
↓
exact Responsibility R
```

This does not solve first Standing generally.  Real Assertions and real
support relations still require exact positive Standing physiology.  It only
removes one artificial Assertion that restates coordinates already inside
`R`.

What becomes inexpressible without Assignment here:

```text
only Standing for the removed Assignment object itself
```

That is not evidence of lost constitutional work.

None of those complete coordinates appears in the active assignment events.
The active language may be compressing a clause-local Responsibility revision;
it does not currently establish a universal Assignment physiology.

What becomes inexpressible without Assignment here:

```text

but no such active physiology is presently established
```

## Conclusion

The active Assignment object appears to reify this edge:

```text
Standing
→ Responsibility
```

It duplicates the coordinates already carried by Responsibility, supplies a
durable implementation handle, then requires positive Standing for the new
handle before Responsibility can be read.

The smaller constitutional road is:

```text
current Standing
↓
exact Responsibility R
├── responsible boundary B
├── exact subject S
├── exact Act X
├── Evidence / Authority
├── Scope / Locality
├── limits / Unknown
└── exact durable reference
↓
Act X
```

No inspected use loses an exact distinction under that decomposition.

One possible future exception remains: a real transfer of Responsibility from
one subject to another.  That would require an assigner, assignee, Assignment
Act, occurrence, Evidence, Authority, prior relation, and changed result.  The
current assignment events establish none of that physiology.

Therefore the repository currently supports this orientation:

```text
Responsibility assignment
currently functions as implementation serialization and reference
for exact Responsibility coordinates,
not as an irreducible constitutional subject.
```

That is an investigation result, not an implementation change.  Assignment
event removal, Book revision, and runtime migration remain outside this report.
