# Single-use admission prose subtraction report 001

## Question

Do low-frequency active admission words express exact distinctions, or do any
only connect statements whose coordinate content is established elsewhere?

## Scope

The audit inspected every active Book word used once or twice. It did not
remove a word merely because it was rare.

The following rare words retain exact controls:

```text
before        occurrence order
complete      complete finding-reference extent
distinctions  Compare result content
exhaustive    no omitted coordinate in a bounded extent
attempt       Emission occurrence surface
accepted      destination-boundary result surface
failure       separate Emission Act/result physiology
```

## Removed prose

Three active sentences repeated coordinates stated immediately beside them.

### Current

The clause establishes current coordinates as the exact established
coordinates in one Locality through one exact boundary. The following sentence
then repeated that definition as a reading that `returns exactly those`
coordinates.

It now says only:

```text
Current coordinates are that bounded reading.
```

The repeated words `returns`, `exactly`, and `those` establish no coordinate.
The pronoun `it` in the next clause is replaced by `the exact result`.

### Compare

The Compare clause first states that its binding coordinates are its exact
subjects, exact Compare Act, and Locality. The next sentence renamed those
subjects `input coordinates` without adding a coordinate.

That sentence is removed. `input` leaves active admission.

Two legacy byte-pair Applicability payloads used the narrated Act name `input
Applicability`. Their exact input references remain in separate payload
coordinates, so the Act value is now simply `Applicability`.

### Book overview

The overview said the binding coordinates `bind` the subjects and that several
later surfaces are `separately exact`. Active clauses already state the exact
coordinates of those surfaces.

The overview now states the binding coordinates directly:

```text
exact subjects
+ exact Act
+ Locality
= subject-to-Act binding coordinates
```

`bind`, `these`, and `separately` leave active admission.

## Finding

```text
rare word with exact falsifier       retained
pronoun or demonstrative copy        removed
narrated coordinate alias            removed
repeated bounded-reading prose        removed
narrated Applicability Act value      decompressed
new occurrence or coordinate          none
```

## Disposition

Remove these active admission words:

```text
bind
exactly
input
it
returns
separately
these
those
```

The exact subject, Act, Locality, boundary, occurrence-order, and result
coordinates remain unchanged.
