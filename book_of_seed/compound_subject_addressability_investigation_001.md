# Compound subject addressability investigation 001

Date: 2026-08-23

## Question and boundary

The calculator road is no longer the proving target.  This investigation asks
the generic question underneath both words and numerals:

```text
exact lower-level subjects
+ exact established relations among them
-> one bounded whole W
-> a later Responsibility can address W as its exact subject
```

It does not assume that one universal `Subject Formation` Act exists.  It
distinguishes:

```text
an implementation allocates a subject address before an Act

a producer yields one exact result

a later Responsibility explicitly addresses that result as its subject

a responsible occurrence yields a bounded whole from lower coordinates

co-present lower coordinates are described by an observer as one whole
```

These are not interchangeable.

The investigation uses active Book law first, then current runtime and tests,
then frozen observer findings and history as testimony.  `compound`, `whole`,
`staircase`, `atomic`, and `representation subject` are report language.  They
do not add constitutional nouns.

This report changes no active Book chapter, machine grammar, runtime, test, or
corpus source.

## Direct finding

No active universal subject-formation physiology exists, and none is needed
to explain the live positive roads.

The smallest recovered rule is:

```text
Responsibility R already carries exact subject S
-> R's Act occurrence
-> Yield result W
-> W is one coordinate of Standing concerning S

then, only where another exact Responsibility R2 says so:

W occupies R2's exact subject position
-> R2's own Applicability / Participation / Act / Yield
```

The first Yield does not make `W` a universal new subject.  The later
Responsibility makes the relevant subject position exact.  The result reference
from the producer is the coordinate that lets the consumer address it.

This is already visible in active law:

```text
01.Source.D result
-> each exact carried source-byte position is a 01.Source.D.2 subject

shared-position Measurement result
-> exact ordered relation-path Assertion
-> 04.Compare.B explicitly takes that path result as one input

Candidate Act result
-> exact Candidate
-> 04.Compare.C explicitly declares the Candidate itself as Compare subject
```

The last road is active law but lacks a live `04.Compare.C` implementation.
The first two have live producer/consumer testimony.

The current variable-extent proof gets closer to the word/numeral staircase:

```text
ordered source coordinates
-> complete internal Compare result
-> exact bounded extent result W
-> recurrence Measurement over W results
-> corresponding-coordinate Measurement over recurrent W supports
```

But it combines two limitations:

1. the caller supplies how many extension rungs to execute; and
2. its Compare and Measurement occurrences carry subject payloads but no
   independently addressable exact Responsibility record/branch preceding
   those Acts.

The Locality reader therefore carries those exact yielded results as
Measurement/Compare occurrences, but cannot recover an
`assignment_subject_identity` or equivalent exact branch owner from them.
Under the Standing recovery at `607aa07c`, these are exact yielded-result
availability with incomplete positive subject-relative Standing, not a fully
owned generic staircase.

The open-world scalar observer has the opposite half:

```text
source pressure chooses recurrent variable extents
-> exact scalar ranges and support populations
```

but those findings have no Seed Responsibility, Act occurrence, Yield,
Locality relation, or Standing branch at all.

The exact missing intersection is therefore:

```text
source-derived bounded whole
+ exact responsible producer branch
+ exact Yield/result reference
+ a later declared Responsibility that addresses that result
```

That is narrower than `Subject Formation`.

## 1. What `subject` establishes

Active `02.Acts.A` makes subject one coordinate of one exact Responsibility.
The Responsibility also carries its boundary, Act, Authority, Scope, Locality,
limits, and required relations.  The subject is not classified by the word
`subject`.

Consequently all of these shapes can be exact subjects where a responsible
clause addresses them:

```text
one acquired-material result
one exact byte representation
one exact adjacent byte-pair representation
one source-position reference
one ordered pair of source Assertion references
one Candidate
one relation Assertion
one ordered relation-path Assertion
one prior result
```

They do not become one ontological kind by occupying the same grammatical
position.

The current Identity investigation also matters here:

```text
new_identity("...")
-> one opaque machine address
```

does not establish:

```text
a new constitutional subject exists
two addresses are constitutionally different subjects
several carried coordinates form one whole
```

An opaque address can make an already-declared machine position retrievable.
It cannot supply the producer, rule, boundary, or relation that warrants the
position.

## 3. Existing representation rungs

### 3.1 Occurrence is not representation

Material acquisition preserves exact source occurrences.  Two occurrences
carrying equal bytes remain two occurrences.  Equality of material does not
collapse their occurrence references.

### 3.2 One-byte representation subjects exist

The live exact-byte Measurement groups exact source material by byte value.
Its count and recurrence Assertions carry subjects of this shape:

```text
{
    representation: exact byte value,
    measurement_rule: exact byte Measurement rule
}
```

Each finding preserves its bounded source population and support.  This is
the nearest current live road to:

```text
many occurrences
-> one same-representation subject
```

It establishes no letter, digit, Unicode scalar, glyph, number, or character
class.

### 3.3 Two-byte representation subjects exist

The live adjacent-byte-pair Measurement similarly carries:

```text
{
    representation: [first exact byte, second exact byte],
    measurement_rule: adjacent byte-pair rule
}
```

Source adjacency warrants the two-coordinate aperture.  The rule exhausts the
exact bounded pair population and preserves count/recurrence findings.

This is a genuine compound representation subject at length two.  It is not a
general construction rule.  The pair's extent is fixed by the declared
adjacent-pair Measurement, and no current clause extrapolates that subject
shape to every length.

### 3.4 Scalar and glyph remain outside the live road

The open-world control established:

```text
transport byte position
!= decoded Unicode-scalar position
```

The active live Measurement surface is byte-based.  It cannot lawfully call a
multi-byte scalar one atomic subject merely because an observer decoded it.
`glyph` is stronger still and has no current exact source coordinate.

Therefore the proposed human rendering:

```text
scalar / glyph occurrences
```

must presently be split:

```text
byte occurrences                         live
decoded scalar occurrences               observer only
glyph occurrences                        not established
```

### 3.5 Variable extents are results, not yet compound-representation Assertions

At this checkpoint, the road now located at
`seed_runtime/source_position_recurrence.py` preserved for consecutive source
positions:

```text
ordered source-position coordinates
complete internal pairwise same/different findings
prior extent result reference
only newly introduced Compare references
```

The result is exact and mutation-checked.  It can be referenced by recurrence
and coordinate-material Measurements.

It does not currently assert:

```text
all supports carrying this literal extent instantiate one compound
representation subject independent of source occurrence
```

Its recurrence key deliberately keeps only the complete internal
same/different surface.  Corresponding-coordinate Measurement later recovers
literal values per role.  No current Responsibility contracts consecutive
same-support coordinate/material findings into one addressed bounded literal
result.

That earlier vacancy remains exact:

```text
consecutive coordinate/material recurrence findings
+ same exact support population
-> one bounded literal result
```

Such a result could be a producer output.  It need not be called a word,
numeral, token, or subject formation.

## 4. Positive recursive testimony

The architecture does permit results and relations to become later subjects,
but only locally.

### D.2 source-position continuation

```text
direct position Measurement result D
-> each exact carried source position q
-> exact D.2 Responsibility subject q
-> D.2 result carrying adjoining pair references
```

The source-position population comes from the producer's exact result, not
from newly minted assignment names.

### Ordered-path continuation

```text
shared-position Responsibility
-> ordered relation-path Assertion P

current Standing carrying P and one exact pair-finding result F
-> active/live 04.Compare.B subject positions (P, F)
-> Compare result
```

The later runtime first enumerates every unassigned `(P, F)` surface carried by
the exact current Locality projection.  It then serializes each exact
Responsibility before Applicability and Participation.  The new
`assignment_subject_identity` is a handle for that already Book-declared input
surface; it is not what made P or F exist.

### Candidate continuation

```text
Candidate Act
-> exact Candidate C carrying source Assertion coordinates

active 04.Compare.C
-> Responsibility subject = C
```

This is the clearest active-law statement that one produced result may occupy
a later subject position while retaining its carried lower coordinates.
There is presently no live implementation of `04.Compare.C`; current tests
verify only the Book/machine projection.

These roads support:

```text
subjects
-> results/relations
-> later subjects where explicitly declared
-> further results
```

They do not support:

```text
every result automatically becomes a subject
every co-carried result pair becomes one compound
all applicable mathematical constructions are attempted
one generic dispatcher scans all Responsibilities
```

## 5. The live variable-extent proof is transitional physiology

The focused runtime proof successfully demonstrates:

```text
minimal adjacent bounds
-> complete internal Compare
-> recurrence
-> one-coordinate extension of recurrent productions
-> reuse of prior Compare work
-> corresponding-coordinate material Measurement
```

The positive witness finds `+` and `=` recurrence at roles the caller did not
name.  The control keeps the same internal equality surface while refusing
literal recurrence for varying role material.

That is real evidence that a source-derived bounded result can feed later
work.

It is not yet a normal current-Standing branch road:

```text
normal live family
    exact Responsibility serialization carrying subject S
    -> Act occurrence cites that earlier R
    -> Yield/result
    -> Locality Standing carries result beside exact branch ownership

variable-extent proof
    direct result is required in Locality Standing
    -> helper writes Act payload containing `subject`
    -> Yield/result
    -> Locality reader classifies result by family
    -> no exact earlier Responsibility/assignment occurrence is recorded
```

The module's `_record_yielded_result()` allocates Act and result identities,
records the Act, records Yield Evidence, and records the result.  It never
records the exact Responsibility branch that active `02.Acts.A` says precedes
the Act.  A text `responsibility` coordinate is not that branch by itself.

This matches the runtime discrepancy recovered at `607aa07c`:

```text
exact yielded result with no Responsibility ownership reference
-> available exact result
!= complete positive Standing coordinate for an exact branch subject
```

The proof also accepts:

```python
extension_count = caller-declared nonnegative integer
```

Within each requested rung, recurrence decides which productions survive and
extend.  The caller does not choose a particular extent or literal.  The
caller nevertheless decides when the complete road stops even if another
recurrent rung exists.

Thus the proof establishes mechanics and bounded source pressure.  It does
not yet establish an independently exhaustive elevator.

## 9. First vacancies in order

### Boundary control: isolation must not decide the result

The present concatenation and host chunking create exact edge effects.  The
right response is a cat test, not a new prerequisite:

```text
run the same exact material as one concatenated acquisition population
run it again as separately acquired source values

compare every recovered bounded finding by its exact carried material,
internal surface, and support coordinates after accounting for the changed
edge coordinates
```

Interior findings should agree.  Findings existing only at concatenation joins
remain join-local.  Findings hidden by transport gaps remain unavailable in
that run.  No run becomes privileged merely because its boundary matches a
human book.

This is validation pressure, not the first missing staircase operation.

### Vacancy 1: make the live bounded-extent producer a complete exact branch

The current variable-extent algorithm already knows how to enumerate its
minimal subject population and how recurrence makes later extents
addressable.  What it lacks is the ordinary preceding exact Responsibility
branch for each Act/result.

The narrow recovery question is:

```text
which existing declared Measurement Responsibility coordinates
make each exact source-derived extent subject addressable before its Act?
```

This is not a request for a new Subject Formation Responsibility.  Active
`01.Source.D` is already broad enough in law.  The runtime specialization must
either instantiate that existing shape honestly or report why one required
coordinate cannot be represented.

### Vacancy 2: contract same-support literal coordinates

Even after a bounded extent result is responsibly owned, the current road
still distinguishes:

```text
recurrence of internal equality surface
corresponding literal material recurrence at each role
```

No current Responsibility produces one exact bounded literal result from
consecutive role findings carrying the same exact support population.  That
is the first missing producer for a repeated compound representation.

The producer's result, not a new universal subject kind, can then be addressed
by a later exact Responsibility.

### Vacancy 3: generic continuation remains separate

No general elevator is required to prove the first compound.  One explicit
producer/consumer join is enough:

```text
responsibly yielded bounded literal result W
-> one already-declared later Responsibility whose exact subject position is W
```

Automatic uptake across every Responsibility remains a later and independent
question.  It must not be smuggled into compound production.

## 10. Answer to the proposed ladders

The proposed generic ladder is directionally sound after correction:

```text
material occurrences
-> same-representation findings under one exact rule
-> ordered relations supplied by one exact bounded source rule
-> responsibly yielded compound result
-> later Responsibility explicitly addresses that result
-> further relation/result work
```

It is not yet warranted to render every rung as:

```text
glyphs -> words -> numerals -> operators -> expressions
```

Those are post-hoc domain names.  The same mechanics may produce bounded
surfaces that human grammar does not call any of them.

The math ladder must also preserve this hard split:

```text
numeral representation subject
!= number subject
```

Source-derived ordered glyph/byte relations may eventually yield a numeral
representation.  A separately warranted domain relation must connect that
representation to an exact number subject.  Successor, equality, order, and
arithmetic then concern the number subjects, not merely the source bytes that
render them.

The architecture has no fixed recursion ceiling:

```text
result/Assertion W0
-> exact subject of Responsibility R1
-> result W1
-> exact subject of Responsibility R2
-> ...
```

The current implementation does have a concrete ceiling, because the next
source-derived producer/consumer joint is incomplete and corpus event
rendering explodes before it.

## 11. Exact stop and disposition

This investigation establishes:

```text
subject is one exact Responsibility position, not a material species
machine subject address != subject warrant
one-byte and adjacent two-byte representation subjects are live
result-to-later-subject physiology is active and partly live
Candidate demonstrates neutral bounded wrapping but no relation
variable extent demonstrates source-derived compound mechanics
open-world observers demonstrate unbiased extent discovery
no universal Subject Formation Act is established or required
```

It locates the current staircase stop:

```text
source-derived variable extent
├── unbiased source pressure exists in observer form
├── exact Yield/result exists in focused live proof form
├── normal exact Responsibility ownership is absent from that proof
├── same-support bounded literal contraction is absent
└── generic later uptake is absent
```

The math-book road carries exact transport edge limits, but those limits do
not create an earlier universal stop.  They bound only findings that require
the affected edges.

Disposition:

```text
universal Subject Formation Act                    refused
word / numeral / expression constitutional species not warranted
new math subsystem                                 refused
calculator oracle                                  unnecessary
active 01.Source.D / D.1                           nearest existing owner
isolated math-source boundaries                     control, not prerequisite
concatenation/transport edge effects                 preserve as exact limits
Responsibility-owned variable-extent specialization first runtime recovery
same-support bounded-literal producer              next exact vacancy
numeral-to-number relation                         later domain boundary
```

No implementation is authorized by this report.  The narrowest next build,
if accepted, is not `form subject`.  It is:

```text
make the existing live variable-extent Measurement road instantiate its exact
01.Source.D Responsibility branch before each Act, using the subject
population the source/recurrence result already makes addressable
```

The first proof should remain small.  Corpus scale must wait until the current
durable event rendering no longer projects hundreds of millions of lifecycle
events.
