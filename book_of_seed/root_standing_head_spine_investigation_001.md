# Root, Standing, HEAD, and spine investigation 001

## Question

Does the current repository need Root, Standing, HEAD, and spine, or has one
word been doing another word's work?

## Active material

The active Book and Witness Grammar carry Standing. Runtime Standing reads the
current exact coordinates concerning one subject at one boundary.

Before this investigation, active Book grammar carried no Root or HEAD. Rosetta
admitted `root` as ordinary language. `spine` appeared only in repository and
Rosetta orientation prose and in `scripts/test_spine.py`.

Historical HEAD reports used HEAD for two different jobs:

```text
Responsibility as the Book traversal entrance
Standing as the later reading entrance
```

The active Book retained neither use. It now states current Standing directly.

Commit `635a22ca` removed two different `root` uses together:

```text
root_references -> source_references
standing.root   -> removed
```

The first correction was exact: Witness, Book material, separate admission
material, and this Seed were sources or subjects, not Roots. That commit did
not separately test whether Root names the bounded whole containing exact
coordinates and relations.

## Distinctions

### Root

One Root is one exact bounded subject from which its exact coordinates and
relations are addressed.

Root is the whole, not its first coordinate.

```text
sentence material
└── exact internal material and relations

pytest collection
└── exact pytest node addresses

this Book
└── Standing, Responsibility, relations, and clause coordinates
```

Root addresses the bounded whole. Standing concerning that subject carries
its current exact coordinates.

### Standing

Standing is not one coordinate. Standing for one exact subject carries that
subject's current exact coordinates.

```text
external sentence Root
↓ acquisition and later responsible work
current Standing concerning that Root
```

The sentence remains one external Root. After acquisition and responsible
work, this Seed's current Standing can carry coordinates concerning that Root.

### HEAD

HEAD may name one exact internal subject that organizes relations within one
Root. The current repository establishes no such general relation.

For material a person reads as `the cat jumped the fence`, the sentence may be
one Root. Which internal subject, if any, is HEAD requires exact language
grammar concerning that sentence. Human recognition supplies no such relation.

HEAD therefore remains Unknown and unadmitted.

### spine

`spine` names no remaining distinction. Current uses compressed:

```text
Book chapter coordinates
Responsibility -> Act occurrence -> Yield -> result
pytest node collection
```

Each already has exact material. The word adds no coordinate or relation.

## Test command

The former `test_spine.py` is an executable command, not the test Root. Its
pytest collection is the Root used by that command. The exact name is therefore:

```text
run_test_root.py
```

The command collects the Root once, divides its exact node addresses, and runs
them.

## Disposition

```text
Root       admitted for one exact bounded whole
Standing   current exact coordinates concerning one subject; not a coordinate
HEAD       Unknown; no active general relation
spine      removed; no distinct work found
```

The Witness Grammar records only:

```text

```

It does not place Standing inside a generic Root coordinate list and does not
create a HEAD coordinate.
