# Limits coordinate investigation 001

## Boundary

This is findings only at repository tip `7b5a16e7`. It changes no active Book,
machine grammar, or runtime behavior.

The question is:

```text
Does one universal limits coordinate perform an exact job
that Scope, Locality, exact boundaries, known loss, conflicts,
Unknown, subjects, rules, and exact occurrences do not already perform?
```

Ordinary material can be limited. This investigation does not dispute exact
bounds. It tests whether every Responsibility, relation, result, and Standing
coordinate also requires one constitutional list named `limits`.

There is no Limits clause, relation, Responsibility, Act, occurrence, or

Responsibility, but it does not state what those limits are. The universal
requirement therefore cites a coordinate whose own anatomy is absent.

## 3. Readers preserve or compare prose; none applies it

Every live read of `limits` does one of these:

```text
copy the list
require that the value is a list
compare the whole list with an authored constant
recompute the complete recorded result and require exact equality
name `limits` among the coordinates of a yielded result
```

No live reader:

```text
reads one sentence to choose work
derives a boundary from one sentence
changes an iteration count from one sentence
stops at a source coordinate named by one sentence
establishes known loss from one sentence
relates one sentence to an exact Act position
```

The strongest direct example is the byte-pair Assertion reader. It requires:

```text
limits == BYTE_PAIR_LIMITS
```

where `BYTE_PAIR_LIMITS` contains one sentence saying the count or recurrence
is bounded by the measured pair and its order. The actual count and recurrence
are computed from the exact pair, source occurrences, rule, and Scope. The
sentence is checked for equality but is never used to perform that work.

The source-position Responsibility reader is weaker. It requires only:

```text
type(limits) is list
```

and does not inspect the list contents.

This is the same distinction that exposed Authority:

```text
a shape is required by a reader
!=
the shape performs a separate grammatical job
```

## 4. Exact bounds already have exact coordinates

The current runtime contains bounds that do alter the work:

| Exact bound | Current coordinate | What it changes |
|---|---|---|
| source address | source boundary / source occurrence references | which supplied material is addressed |
| prior ledger address | Standing boundary | which prior occurrences are available to the exact work |
| completed read address | completeness boundary | which source occurrences the Measurement must account for |
| produced result address | result boundary | which exact result the Responsibility owns |
| place | Locality | where the occurrence and relation are exact |
| addressed work | Scope | which subjects, relations, Acts, occurrences, results, and Localities are addressed |
| rule | exact rule | which findings the Act must produce |
| pair-occurrence count bound | `occurrence_limit` | how many exact pair occurrences are carried |
| omitted exact material | known loss | which available occurrences were not carried |
| unresolved material | Unknown | what the exact occurrence does not establish |
| incompatible material | conflicts | exact carried conflict material |

The pair-occurrence witness makes the distinction concrete:

```text
occurrence_limit = 2
available exact occurrences = 4
carried exact occurrences = 2
known loss = the later two occurrences are not carried
```

Changing `occurrence_limit` changes the result and is refused by replay. The
nearby `limits` prose merely says that the work is bounded by the occurrence
limit. It does not carry the integer and does not govern the loop.

Thus:

```text
exact bound                         real and active
prose describing the exact bound    duplicate coordinate
```

## 5. The inward story does not establish a separate job

The frozen inward-story refusal operation found `limits` on the `D -> D`
edge. Changing or removing that top coordinate is refused by the later reader.

The exact list there is:

```text
bounded to one exact direct pair-position Measurement result,
source occurrence, Locality, completeness boundary,
and addressed coordinate

establishes no recurrence, shared position relation,
represented relation, or other relation
```

Every positive coordinate named in the first sentence is separately carried
and separately required on the same edge. The second sentence is a blacklist
of relations the exact occurrence never established.

The refusal operation proves:

```text
the present D reader requires this exact authored list
```

It does not prove:

```text
the first sentence owns any bound
the second sentence establishes any negative relation
the list changes what D addresses or produces
```

This is stricter than the old Authority case because the exact text is checked.
It is not stronger physiologically: the reader checks authored prose while the
actual source, Locality, completeness boundary, addressed coordinate, rule,
and result are enforced through their own exact coordinates.

## 6. History identifies the compression

The earliest broad Book placed bounds among `Constraints, Policy, and
Preconditions`, beside approval and refusal machinery. It did not establish a
single limits relation or Act.

Commit `4d4a5f3f` made the runtime name explicit:

```text
boundary_notes -> limits
```

The values did not change jobs. They remained sentences such as:

```text
a finding reports a count within its stated scope and nothing further
recurrence establishes ... only
a highest-count occupant ... is not ...
```

Commit `f956b6fd` then placed `limits` into the compact universal
Responsibility and relation anatomy during a 5,329-line grammar contraction.
That commit did not add a limit-producing occurrence or a reader that applies
one.

Commit `58c8c7ca` later removed ten denial sentences because exact positive
coordinates already settled them. Current `limits` lists retain the same
blacklist shape inside runtime material.

The historical path is therefore:

```text
boundary notes and policy denials
-> key renamed limits
-> key placed in universal grammar
-> exact boundaries later carried separately
-> prose list retained
```

No earlier finding was located that established a distinct universal limits
physiology before that promotion.

occurrence. `Unknown`, conflicts, and known loss already have separate
coordinates where those distinctions are actually carried.

Disposition: none presently demonstrated. Any future exact negative relation
must enter through its own responsible occurrence, not through a sentence in a
generic list.

### D. Unique universal limits physiology

No subject, relation, Responsibility, Act, occurrence, result, or reader
decision was found.

Disposition: not established.
