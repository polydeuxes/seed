# Recorded relation testimony Act-owner investigation 001

Date: 2026-08-23

## Question and boundary

`bounded_number_prior_standing_investigation_001.md` recovered the lawful
boundary skeleton for work over new material:

```text
exact prior append boundary B
+ exact recorded testimony T
-> Responsibility-specific input rule
-> Applicability / required Admission / Participation
-> Act occurrence
-> Yield
-> result through C
-> completeness replay relative to B, T, and the rule
-> possible later Standing movement
```

Its last revision nevertheless compressed the unresolved middle into a
`generic responsible Standing-establishment crossing`.

This investigation withdraws that compression and asks only:

```text
Which existing exact Responsibility and Act, if any,
accept one recorded relation testimony as an input
and can Yield the substantive result from which relation Standing may later
be warranted?
```

The search proceeds by exact subject coordinates, not names. A module is not a
candidate owner because its filename contains `standing`, `relation`,
`compare`, or `applicability`. It is a candidate only if the recorded testimony
can satisfy its declared input position and its rule bears on the testified
relation.

This report changes no active Book chapter, Witness Grammar, runtime, script,
or test.

## Direct finding

No active owner reaches the proposed transition.

The first vacancy is earlier than Standing movement and earlier than
Applicability:

```text
recorded relation testimony T
+ current boundary B
-> no active Responsibility assignment condition addresses T
   as an input to one exact substantive Act X
-> no exact T-to-X subject position exists
-> Applicability has no addressed position to evaluate
-> Participation cannot occur
-> X has no occurrence or Yield
-> no result exists from which later Standing could move
```

`X` is a report variable, not a proposed Seed Act or constitutional kind.
Nothing in this finding warrants a generic relation-testimony judge, generic
Standing-establishment Responsibility, or automatic promotion of testimony.

The bounded number experiment therefore stops before successor-path work.

## 1. The active order of ownership

### 1.1 Recording owns preservation only

`05.Recording.A` permits one recording occurrence to preserve one exact
Assertion and its source coordinates. `05.Recording.E` gives the recording Act
its own Yield and record.

That establishes:

```text
T exists at an exact durable address
T retains its source coordinates and recording boundary
```

It does not establish:

```text
T is applicable to some unspecified Act
the relation asserted by T occurred
T has relation Standing
T changes current Standing
```

Recording therefore supplies an addressable input only after another exact
Responsibility declares that a recorded Assertion is one of its subjects.

### 1.2 Responsibility assignment precedes Applicability

`02.Acts.A` requires one exact Responsibility to bound one exact Act and carry
its subject, Authority, Scope, Locality, limits, and required relations.

`01.Standing.E.1` then gives Applicability a narrower subject:

```text
one exact subject-to-Act position
```

The result is one of:

```text
applicable
inapplicable
conflicting
Unknown
```

Applicability is therefore unable to answer:

```text
Which Act should consume T?
```

It can answer only:

```text
Given already-addressed Act X and input position P,
what is the Applicability of T in P?
```

`responsibility_assignments_at_one_boundary_investigation_001.md` already
recovered the same ordering for active runtime:

```text
exact Book-assigned Responsibility known
-> complete exact assignment subjects
-> Responsibility assignment
-> Applicability
-> Participation
```

Inverting this road would make Applicability discover the Responsibility that
defines its own subject position.

### 1.3 Participation does not repair a missing Act position

Participation is the exact relation from one subject and one Act-local role to
one exact Act occurrence. It requires the exact applicable subject-to-Act
position.

Co-presence of T and an Act occurrence cannot manufacture that relation. Nor
can a caller attach an arbitrary `input` role and thereby establish the Act's
Responsibility.

### 1.4 Standing is downstream of the ordinary result

`01.Standing.A` requires an exact Responsibility, Act occurrence, Yield,
Authority, Scope, limits, and result for the exact subject. Under
`01.Standing.A.1`, the result is a coordinate of Standing for the subject of
that Responsibility branch.

This does not name a universal Standing-movement Act. It says what an exact
responsible branch must carry after its own result exists.

Consequently the current question cannot begin at:

```text
How does T move Standing?
```

It must begin at:

```text
Which substantive Act has T as an exact proposed input?
```

## 2. Exact owner pressure

### 2.1 `01.Source.F`: the relation is already carried

`01.Source.F` applies when supplied material already carries a relation
Assertion. Carriage preserves that Assertion and its source coordinates.

Its input position is:

```text
supplied material carrying an already-addressed relation Assertion
```

Its output distinction is preservation across the source boundary. It does not
determine whether the asserted relation occurred, establish a responsible
relation occurrence, or warrant relation Standing.

For bounded successor testimony this means Source.F may preserve the exact
shape:

```text
sable --R--> fern
```

only once that relation Assertion is already supplied as such. It cannot be the
substantive Act whose result decides what Standing that testimony warrants.

### 2.2 Candidate: a neutral continuation, not warrant

`01.Source.E.1` and
`candidate_results_from_exact_result_assertions.py` accept exact source
Assertions as subjects of one-source and ordered-pair Candidate Acts.

This is the broadest current road on which a recorded Assertion can continue:

```text
source Assertion
-> Candidate input Applicability
-> Participation in exact Candidate Act
-> Candidate result
```

The result explicitly preserves:

```text
relation: Unknown
Candidate Act establishes no source Assertion relation
```

A later Candidate Act can consume the resulting Candidate Assertion again as
a source Assertion. That recursive uptake remains neutral. It does not warrant
the testified relation or assign it to another non-Candidate Act.

Candidate therefore proves that recorded material need not be terminal. It
does not own the required substantive crossing.

### 2.3 Representation emission Applicability: exact but different coordinates

The live Representation road is a positive example of family-local ownership.
It begins only after these coordinates already exist:

```text
one exact Representation candidate
one exact Admission result
one exact emission Act and occurrence
one exact destination operator boundary
one exact Representation-rule-to-boundary-rule relation
current Admission Standing
```

`operator_representation_applicability.py` validates the exact admitted
Representation rule against the exact destination boundary rule. Its result
records Applicability only for that input-to-emission-Act position and
explicitly establishes no Participation or emission result.

Recorded successor testimony supplies none of those subject coordinates. The
module cannot be generalized by the shared word `Applicability`; its owner is
the exact Representation emission Responsibility.

### 2.4 Declared Measurements: their rules select other subjects

The active declared Measurement roads accept family-specific populations:

- an exact acquired material result, its Yield, and its material-to-this-Seed
  Locality relation;
- exact source-byte positions carrying a direct pair-position Measurement
  result;
- exact recurrent byte-pair Assertions plus a later acquired material result;
  or
- variable-extent Compare results under their explicit proving boundary.

Those rules can measure exact material, findings, counts, positions, and
recurrence. None declares one recorded substantive relation testimony as its
subject and none yields whether that testified relation warrants Standing.

Running successor testimony through byte or extent Measurement would inspect
its serialization. It would not make the supplied relation the subject of a
relation-warranting Act.

### 2.5 Current Compare owners: exact distinctions, wrong subjects

The generic `04.Compare` clause can constitutionally carry exact subjects and
an exact rule. That grammar does not itself instantiate a live Compare
Responsibility.

Every active or live Compare surface inspected has a narrower input surface:

- two exact byte-pair Measurement results;
- one exact ordered byte-position relation-path Assertion and one exact
  recorded pair-finding Compare result;
- under active `04.Compare.C` law, one exact Candidate carrying first and
  second source Assertion coordinates (no live Candidate-Compare writer was
  found);
- exact source-position material carried by one local byte boundary; or
- exact coordinate roles inside one variable extent.

For example, the ordered-path/pair-finding road requires a shared-position
Measurement result whose one Assertion is `ordered_relation_path`, plus a
specific pair-measurement comparison result from the same source occurrence.
Its Applicability checks that both path pair subjects have matching recorded
findings. Its result explicitly establishes no source relation or recurrence.

An opaque testimony edge does not satisfy those coordinates. Even if two
testimonies could be compared, literal sameness or difference between them
would not by identity warrant the relation either one asserts.

Compare remains a possible kind-specific owner only after an exact comparison
Responsibility and rule make T one of its subjects. No active assignment does
so here.

### 2.6 Locality and Movement: preservation after an addressed relation

The Standing Locality continuation roads accept exact prior Standing-boundary
references or exact Representations and preserve one direct Locality relation.
Their own limits state that availability is not Applicability or Participation
and that the relation carries no other addressed Standing.

`03.Movement.A` likewise preserves an exact subject and an exact
source-to-destination relation under its movement Act. It does not evaluate a
substantive relation asserted by T.

These roads can transport an already-addressed coordinate. They cannot supply
the missing Act position.

### 2.7 Current Standing readers classify completed family results

`operator_locality_standing.py` validates known event kinds and places their
completed results in family-specific carried populations such as Measurement,
Compare, Candidate, Applicability, assignment, or recorded relation-Standing
occurrences.

This is a downstream read over occurrences already produced by their owners.
The event-kind branches do not prospectively discover a Responsibility for an
unassigned testimony. Adding a new event-kind case would classify a result
after the fact; it would not establish the missing substantive Act.

## 3. Bounded successor testimony at the exact stop

Let the permitted testimony carry opaque subjects and an uninterpreted exact
relation identity:

```text
T0: sable --R--> fern
T1: fern  --R--> cobalt
```

The experiment may also carry exact origin testimony, bounded Authority and
Scope, and Unknown beyond its finite boundary.

The active topology can reach these positions:

```text
exact material acquisition / source occurrence                 yes
record exact Assertion and source coordinates                  constitutionally yes
preserve supplied material carrying a relation Assertion       yes
preserve T0 or (T0,T1) as neutral Candidate material           where the source surface addresses it

```

It cannot reach:

```text
Responsibility assignment whose declared subject is T0         no active owner
exact substantive Act X addressed by that assignment           no
T0-to-X Applicability position                                  no
Participation of T0 in X                                       no

later relation Standing warranted by X's result                no result exists
```

The first `no` controls every later one. Supplying an
`applicability = applicable` event would not repair it because the event would
have no lawfully addressed Act position.

## 6. Exact vacancy and stop

The previous orientation asked for a generic crossing from testimony to
Standing. The owner trace does not warrant that abstraction.

The exact active vacancy is:

```text
For one recorded bounded relation testimony T at boundary B,
no active Responsibility assignment condition identifies T as an exact input
to a substantive Act whose declared rule bears on the testified relation.
```

Therefore:

```text
exact Act owner absent
-> subject-to-Act position absent
-> Applicability cannot be determined
-> Participation cannot be recorded
-> no substantive result exists
-> later Standing movement is not yet the active question
```

This finding does not establish what that Act should be. It may ultimately be
a recovered kind-specific Compare, another already-existing Act whose subject
surface has not yet been connected, or a genuinely missing responsibility.
Choosing among those possibilities requires an exact rule and evidence that
bear on the relation. The finite testimony population and developer intent do
not supply them.

Disposition:

```text
no current owner reaches recorded relation testimony
-> report the missing Act-position owner
-> do not implement a generic Standing-establishment Responsibility
-> do not begin successor-path derivation
-> STOP
```

## What this does not establish

- It does not establish that prior domain testimony is unusable.
- It does not establish that Compare must or must not own the eventual work.
- It does not establish that recorded testimony is applicable, inapplicable,
  conflicting, or Unknown with respect to an unaddressed Act.
- It does not create relation Standing from source carriage.
- It does not make Candidate a global source reader.
- It does not identify the eventual ternary consequence or relation content.
- It does not amend the Book merely because runtime lacks an owner.
- It does not propose a generic testimony evaluator, promotion Act, or Standing
  mover.
