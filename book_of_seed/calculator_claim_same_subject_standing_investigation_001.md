Date: 2026-08-23

## Question and boundary

```text
Responsibility subject S
-> Act occurrence
-> Yield R
-> R is one coordinate of Standing concerning S
```

This investigation applies that rule to the historical toy-calculator and
`2+2=5` campaign.

The operator recalled roughly 217,000 references that appeared to contradict
the claim. Neither the count nor the word `contradict` is accepted as an input
finding. The investigation recovers the exact historical roads and asks, for
every useful-looking result:

```text

```

It does not rerun the sixteen-Book population or the historical calculator
fixture. The committed source, focused tests, reports, and commit chronology
already discriminate the subject topology. No historical EventLedger database
or frozen append-boundary digest for the calculator run is committed, so an
ephemeral event identity cannot be honestly reconstructed from source code.

This report changes no active Book, machine grammar, runtime, test, or script.
