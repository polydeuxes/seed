# Source recurrence and source division relation investigation 001

## Boundary

Findings only. No Book, machine grammar, or runtime change.

`9b1285b7` located the first unsupported cross-surface operation:

```text
exact recurring material B
+ exact source occurrences carrying B
-> use B under one exact source-division rule
```

This investigation asks whether a live recurrence road already owns that
relation. It audits the source-exhausted source-position road and the older
recurrent byte-pair position road. It also measures the source-position rule
against the four raw bootstrap sources without recording new Seed occurrences.

## 1. The source-exhausted road owns continuation

`seed_runtime/source_position_recurrence.py` begins with every consecutive
two-coordinate source subject. For each coordinate count it records the
complete same-content/difference Compare surface and groups identical
surfaces. Every surface carried by more than one exact result continues by one
source coordinate wherever that coordinate exists.

The caller supplies no final coordinate count and selects no recurring
surface. The carried recurrence result supplies:

```text
exact producing result references
+ their exact consecutive source coordinates
+ one next source coordinate where present
-> every next source-position result
```

The road stops when no recurring surface can continue. Thus an exact prior
result already governs both continuation and stopping after the road has
begun.

## 2. Continuation is not source division

The continuation rule preserves the first coordinate and appends the next
consecutive coordinate. It never establishes any of these relations:

```text
recurring material B divides the source
material between two occurrences of B is one subject
B occupies a boundary position
two different recurring materials form rows and positions
```

The later exact-material Measurement is narrower still. It produces one
reusable material result only when every result supporting one structural
recurrence finding carries the same exact material at every corresponding
coordinate. A recurring byte or substring inside only part of that support
does not become a common material result for the whole finding.

Therefore:

```text
recurrence decides whether an addressed consecutive path continues
!=
recurring material decides how a source is divided
```

## 3. The older recurrent byte-pair road does not close the gap

`measurement_of_recurrent_byte_pair_occurrence_position.py` takes two exact
inputs:

```text
one already-recorded recurrent two-byte Assertion
one later exact material-acquisition result
```

Its declared Measurement rule finds each exact occurrence position of that
two-byte material within a supplied completeness and count boundary. This is
positive precedent for a yielded result governing later source work.

The caller still selects that Measurement Responsibility and supplies the
already-recorded pair reference, later source result, and count boundary. The
road is also specific to two bytes. It does not establish a general relation
by which recurring material becomes a source division.

## 4. Blind measurement against the bootstrap material

`scripts/observe_source_recurrence_division_boundary.py` mirrors only the live
source-position equality surfaces and source-exhausted continuation. It starts
from raw bytes. It selects no byte, final coordinate count, surface, or exact
material. The frozen artifact contains hashes, coordinate counts, and source
positions rather than plain source material.

The four sources produce:

```text
source  bytes  recurring surfaces  reusable exact materials  largest coordinate count
0       50     140                 0                         0
1       130    237                 128                       19
2       56     76                  24                        14
3       26     27                  1                         3
```

The symbolic source produces no reusable multi-byte material under this rule.
Its recurring equality surfaces are also carried by different byte sequences,
so the complete supporting results do not agree on exact material. The other
sources produce source-specific fragments in sharply different quantities.

This is a useful refusal. Promoting these exact-material results into source
divisions would privilege the spelling and repetition anatomy of one source.
It would not recover the cross-surface division relation.

The small controls retain the existing exact distinction:

```text
a+aa+a -> one exact three-coordinate material at positions 0 and 3
a+aa-a -> no common exact material for that structural recurrence
```

The observer reports what the live rule would distinguish. Its known loss is
all Responsibility, Act, Yield, result, and current Standing occurrences. It
is not a runtime replacement.

## 5. Execution bottleneck

The full live source-position road records the complete responsible physiology
for every Compare and Measurement occurrence. Measured locally:

```text
6-byte source   0.043 seconds   168 ledger occurrences
12-byte source  0.451 seconds   1,488 ledger occurrences
18-byte source  0.748 seconds   2,580 ledger occurrences
50-byte source  did not complete within 30 seconds
```

The observer computes the four-source summary in less than one second because
it does not record or validate those occurrences. That speed difference does
not warrant omitting the responsible physiology from Seed. It does show that
the current road cannot be used as the bootstrap search harness at this size
without first reducing what work is lawfully owed or finding a cheaper exact
ledger read. Faster persistence would not supply the missing division
relation.

## 6. Exact stopping boundary

The audit recovers this active topology:

```text
declared source-position work
-> every adjacent source-position subject
-> complete Compare surface
-> recurrence result
-> recurrence-governed continuation and stopping
-> optional common exact-material result
```

It does not recover:

```text
recurring material
-> source-division relation
-> divided source subjects
```

No active Book clause, machine coordinate, or runtime reader found in this
audit makes that crossing.

## 7. Smaller next question

The cross-surface experiment need not assume that division is the only route.
The next investigation can ask:

```text
exact source-exhausted recurrence results from separately acquired sources
+ active Compare grammar
-> any exact Compare work already required without a source-division rule?
```

If no exact rule already requires that Compare, the results remain idle. No
new source-divider, delimiter, Candidate rule, or automatic uptake is
warranted by this investigation.
