## 2. Relation-first addressing

Each endpoint relation supplies three one-to-one anchor pairs. The observer
walks both exact orientations.

For each orientation it first addresses only projections that carry every
first anchor material on one side and every second anchor material on the
other. Equal row and coordinate counts are required because this exact walk
compares corresponding coordinates. No source number, material value, desired
projection identity, or desired later correspondence is preferred. Source
numbers remain carried provenance and the frame observer requires unlike
source numbers, as recorded in the later stopping boundary.

The anchor pairs then determine which later rows can answer each first row.
Only complete one-to-one row pairings continue. Within each row pairing the
observer walks coordinates in source order:

```text
already carried pair
-> exact same pair required

new first material + unused later material
-> add one exact pair to this walk

changed pair, one-to-many pair, or many-to-one pair
-> this walk stops
```

Every accepted walk must transform every first row exactly into its addressed
later row. Thus the relation is not used as a label for the later result. Its
own exact material constrains each later step.

## 5. Path discrimination

Group 0 contains 136 projections, hence 18,360 ordered pairs of distinct
projections.

For each endpoint relation, the exact anchor materials reduce that surface to
10 addressed projection pairs:

```text
18,360 ordered projection pairs
-> 10 pairs carrying the exact anchor materials with equal row/coordinate counts
```

For relation 0, those 10 pairs produce two exact row pairings, one for each
orientation. Both coordinate walks complete.

For relation 1, the same count of projection pairs is addressed, but no row
pairing answers all three anchors. No coordinate walk begins.

The observer therefore does not enumerate every complete eight-material
renaming and test the relation afterward. The relation itself removes all but
the addressable projection and row work before new pairs are added.

The implementation still scans its in-memory projection list to locate those
10 pairs. At 0.060 seconds for all four groups, this is not a current time
concern. A future live road would need exact addresses rather than a scan, but
this observer does not authorize that road or an index.

## 6. What the controls establish

### 6.1 An exact relation alone does not establish continuation

Group 1 carries both exact endpoint relations but no larger surface answering
either one:

```text
two exact endpoint relations
-> zero continuations
```

Thus:

```text
exact relation exists
!=
later path exists
```

### 6.2 Later structure distinguishes the relations

Group 0 permits relation 0 to reach one complete eight-pair correspondence
while relation 1 cannot form one row pairing.

Group 2 changes the larger material coherently. The result reverses:

```text
relation 0 -> zero continuations
relation 1 -> one complete correspondence in both orientations
```

The observer has no arithmetic or English rule by which group 0 is true and
group 2 is false. Both are exact source-supported findings.

### 6.3 The operation does not force uniqueness

Group 3 carries both larger surface pairs. Both endpoint relations reach their
own complete eight-pair correspondence.

```text
two exact relations
+ two exact answering structures
-> two continuing relations
```

Nothing chooses one. Ambiguous material produces an ambiguous result.

## 7. Observer-level initiation finding

At this observer boundary, no new frame object is required. The useful state

```text

├── three exact carried material pairs
└── exact orientation

```

This gives the biology-inspired initiation question a narrow answer:

```text

its exact carried pairs remove later work that cannot answer,
and each accepted next coordinate adds exact state for the following step.
```

No relation is promoted merely because it recurs. The relation with no
answering later structure produces no continuation. When two relations both
have answering later structure, both continue.

This is closely analogous to an established biological reading frame making
the next codon locally addressable. It is not an identity between Seed and
biology, and it does not explain how either initiation machinery first becomes
present.
