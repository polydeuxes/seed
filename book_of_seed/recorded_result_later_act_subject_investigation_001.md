# Recorded Result Later-Act Subject Investigation 001

## Question

When does an exact recorded result merely remain readable, and when does it
become an exact subject coordinate of a later Act occurrence?

This investigation asks where the current exact-material road performs the
second operation. It does not infer a general understanding coordinate from a
result being recorded, current, or readable.

## Scope

The control supplies three exact operator-material occurrences successively in
one Ledger and one Locality:

```text
ab\n
ac\n
ad\n
```

Each material is supplied in a separate call of the persistent operator
console. The calls retain the same Ledger and Locality, so a later call can
address exact results recorded by an earlier call.

The experiment uses only existing source, Measurement, Compare,
Applicability, and Distinction Measurement physiology. It adds no runtime
road, Book clause, Act, result kind, or admitted word.

## Rosetta orientation: decompiled is not played

`Decompile` is useful Rosetta orientation for the composite inspected here. It
does not name an admitted Seed Act.

In ordinary software terms, decompiling a Super Smash Bros game artifact can
produce source-like material. That outcome does not mean the game is running,
that anyone is playing it, or that a recipient of the decompiled material
understands what they received.

The analogy translates into current Seed coordinates as follows:

| Rosetta or ordinary word | Exact orientation in this investigation |
| --- | --- |
| game artifact | exact supplied material; `game` adds no Book coordinate |
| decompile / decompiled | the composite passage from exact material through existing Measurements and Compares to exact structural results; no Decompile Act or result is claimed |
| source code | ordinary orientation for recovered structured material; it is not automatically a Seed source coordinate and carries no original author names or intent |
| runtime | the implementation in which later exact Acts may occur; runtime presence is not itself an Act occurrence |
| controller input | orientation for an exact later supplied request; it does not exist in this experiment and does not enter Book grammar |
| use / used | report-local shorthand for an earlier exact result becoming a subject coordinate of a later Act, not a general constitutional Use relation |
| play / played | ordinary shorthand for continuing Act/result composition under later supplied material; no Play Act or result is claimed |
| understand / understanding / grok | no current exact coordinate; none is inferred from recording, reading, decompiling, or later composition |

The analogy gives one discriminator:

```text
decompiled structure recorded and readable
!=
decompiled structure participating as an exact subject of later Acts
```

It adds no semantic conclusion about the material.

## Discriminator

These states are not interchangeable:

```text
an exact result occurrence is recorded

an exact result occurrence is current through a selected boundary

a later reading can jointly address exact result occurrences

a later Act occurrence addresses an exact result as its subject
```

The last state requires an exact later Act occurrence whose subject
coordinates reach the earlier result. Mere inclusion in current coordinates,
use as a through-occurrence boundary, or inclusion in a generic occurrence
position Measurement does not make the earlier result's content a subject of
the later Act.

## Existing result-to-Act composition

After the first supplied material, the Ledger contains an exact byte-pair
Measurement result and no recorded-pair Compare Act or result.

After the second supplied material, the active road records a Compare Act whose
earlier Measurement reference addresses the byte-pair Measurement result from
the first call and whose later Measurement reference addresses the result from
the second call.

The reported occurrence counts after each call are:

| Through supplied material | Pair Measurement results | Recorded-pair Compare Acts/results | Variable Applicability Acts/results | Positive same-position Compare Acts/results | Distinction Measurement Acts/results |
| --- | ---: | ---: | ---: | ---: | ---: |
| `ab\n` | 1 | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| `ac\n` | 2 | 1 / 1 | 2 / 2 | 1 / 1 | 1 / 1 |
| `ad\n` | 3 | 2 / 2 | 6 / 6 | 2 / 2 | 2 / 2 |

This is not a read-only external comparison. The earlier pair Measurement
result is an exact subject coordinate of the later recorded-pair Compare Act.
That Compare result and exact same-position result positions then become
subjects of Applicability Acts. Positive Applicability results address later
Compare Acts, and the resulting Compare results become subjects of Distinction
Measurement Acts.

The active road therefore composes recorded results into later Acts:

```text
exact material result
→ byte Measurement result
→ byte-pair Measurement result
→ recorded-pair Compare Act and result
→ Applicability Act and result
→ same-position Compare Act and result
→ Distinction Measurement Act and result
```

The readers preserve the dependency rather than accepting a copied label.
Existing mutation controls refuse a later Compare reading when its addressed
pair Measurement result changes, and refuse a Distinction Measurement when its
recorded finding reference changes.

## Distinction-result ceiling

The same three-material history produces two exact Distinction Measurement
results. Existing current-coordinate physiology can recover one exact joint
between them:

```text
earlier Distinction Measurement result  evt_000064
later Distinction Measurement result    evt_000105
the same exact Measurement reference    evt_000054
```

The joint is recovered by
`compare_distinction_measurement_references_from_current_coordinates()`.
Capturing the Ledger append boundary immediately before and after that reading
produces the same boundary:

```text
exact joints returned       1
occurrences appended        0
```

The function returns joint addressability in one continuous Locality history.
It records no subject-to-Act binding, Applicability Act or result,
Compare Act, or Compare result.

No active runtime caller consumes the returned joint. The result family is
otherwise consumed by its exact reader, current-coordinate reconstruction,
and declared-Measurement discovery. Those operations keep the occurrences
readable and can measure their occurrence positions, but no later structural
Act addresses the recovered Distinction content as its subject.

Consequently, the current active road has a family-specific compositional
ceiling:

```text
Distinction Measurement results
→ exact readable results
→ one exact read-only joint in this control
→ no later Act over that joint
```

## Invocation is a separate question

The absence of a later Act does not itself mean that a prior occurrence must
autonomously choose one. An exact Act occurrence is the constitutional fact
that the Act occurred; demanding a prior producer for every Act repeats the
regress refused in
`act_occurrence_and_exhaustive_coverage_census_001.md`.

The earlier independently bounded investigation deliberately asked whether
Seed could create a Compare without an authored experiment selecting its
subjects or Act. It correctly froze that autonomous road.

A different future test may ask whether an exact operator-supplied request can
address exact prior results and an exact Act. That shape would not claim that
co-current results select their own Act:

```text
no exact request
→ no later Act required

exact request addressing result A, result B, and Compare
→ exact requested Act occurrence, if such physiology is independently admitted

changed or absent addressed result
→ refusal
```

This report does not implement or admit that request shape. In particular, it
does not infer Compare merely because the read-only joint exists.

## Findings

```text
recorded result
!= later-Act subject

current result
!= later-Act subject

joint addressability
!= Act occurrence

read
!= Act
```

The current exact-material road nevertheless demonstrates real result-to-Act
composition below the Distinction-result ceiling. The earliest live absence in
this control is not decompilation of exact structure; it is a later Act whose
subject coordinates address the recovered Distinction result content.

## Disposition

The positive result-to-Act ladder survives. The Distinction-result joint
remains a read-only coordinate and authorizes no new Act.

The next investigation should census exact operator-request physiology before
any new comparison road is considered. It must distinguish an exact supplied
Act request from co-current result discovery and must not promote a readable
joint into an Act by itself.
