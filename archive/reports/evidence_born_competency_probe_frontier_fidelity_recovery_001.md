# Evidence-Born Competency-Probe Frontier Fidelity Recovery 001

## Scope, authority, and governing answer

This is one bounded, report-only Fidelity recovery on the current merged state
after PR 2006. It changes no implementation, test, fixture, schema, export,
interface, event, persistence, projection, canonical Book chapter, root
documentation, `docs/` content, or prior report. Historical reports are used as
leads and counterevidence only. Current implementation, tests, and the active
Book control.

**Governing answer:** the two specimens stop at different crossings.

* The external-material road has real, source-addressable occurrence-bearing
  input. A successful structural projection returns the exact physical line
  occurrences of one hash-checked supplied artifact; its surface-feature
  projection returns measurements keyed back to those line and region
  occurrences. A responsible examiner retaining those returned values can
  declare a bounded PESC comparison without inventing occurrence identity.
  Current Seed, however, has no producer that performs that comparison over
  these projections. The active road stops at **occurrence-bearing structural
  measurements available to comparison**.
* Each initial-goal ingress producer returns a detailed evaluation artifact,
  including a refusal when appropriate. That value evidences the result content
  of the invocation to the immediate caller, but the road neither records the
  invocation nor gives equal invocations distinct occurrence identities, time,
  order, or episode membership. It therefore stops one crossing earlier, at a
  **returned ingress artifact**, before occurrence-bearing evidence history is
  available to multi-occurrence examination.

Accordingly, PR 2006 correctly denied recurrence and correctly stopped before
pressure or Demand, but it did **not** identify the first missing crossing. Its
first `-X->` joined “separately retained artifacts” directly to a recurrence
finding. For initial-goal ingress the prior crossing is already absent:

```text
returned ingress artifact
  -X-> occurrence-bearing evidence available to examination
  -?-> PESC-relative comparison
  -?-> bounded recurrence finding
  -?-> consumer-local materiality finding
```

The evidence does not warrant assigning both stops to one implementation owner
or declaring a universal competency probe. It does support the narrower
constitutional ordering that an occurrence must be represented and available
before it can be compared. Whether a recurring implementation responsibility
called competency probing or evidence preservation should own both crossings
remains **Unknown**.

## Controlling orientation and bounded PESC role

The following non-equivalences govern this recovery:

```text
Structure Probe = compiled measurement instrument
Documentation Probe = compiled destination realization
compiled behavior != competency standing
PESC = recurrence disclosure discipline != entire competency probe

artifact construction != occurrence
returned artifact != preserved evidence history
reconstruction != prior occurrence
multiplicity != recurrence
recurrence != explanation
PESC-relative count != competency standing
compiled observer behavior != evidence-born competency
comparison availability != consumer Uptake
consumer purpose != universal routing
BOGE refusal evidence != BOGE-owned recurrence responsibility
```

The active Book authorizes a declared measurement to report exact equality,
count, recurrence, prefix occurrence, declared-predicate result, or adjacency
only within its measurement boundary. For a recurrence assertion it requires:

* **P — projection or representation examined**;
* **E — declared equivalence or sameness rule**; and
* **S — bounded comparison/counting scope**.

The consumer's purpose, **C**, separately governs lawful reliance, acceptable
aggregation, and acceptable loss. It need not be embedded in every exact count.
Thus PESC is useful here as a four-question disclosure discipline at the
comparison-to-reliance seam. It is not a repository object, universal request
schema, producer, recorder, routing system, competency-establishment rule, or
substitute for occurrence identity. PESC can disclose that identity is absent;
it cannot create it.

## Specimen A — external exact material to structural measurements

### Exact current road

```text
ExternalMaterialManifest
+ ExternalMaterialStructuralProjectionRequest(exact_text, encoding,
  expected_artifact_hash, manifest/source/artifact identities)
  -> project_external_material_structure(...)
  -> ExternalMaterialStructuralProjection
       exact projected lines + maximal nonblank regions
  -> project_external_material_surface_features(...)
  -> ExternalMaterialSurfaceFeatureProjection
       line and region measurements tied to structural projection identity
  -X-> active PESC-relative comparison producer
  -X-> bounded recurrence finding for an exact declared consumer
```

The manifest/request boundary validates manifest, source, artifact parentage,
expected hash, encoding, actual encoded-text hash, line count, and character
count. On success, `splitlines(keepends=True)` produces ordered physical-line
slices. Each returned line has a stable line id, one-based line number,
half-open character coordinates, exact text, count, blank flag, terminator flag,
and Unknowns. Maximal adjacent nonblank lines become region records with their
ordered line ids. This is the actual occurrence-bearing representation: line
membership is not inferred later from a count.

The feature producer validates unique line/region identity and ordered region
membership. It emits per-line raw, content, and terminator character counts and
per-region ordered count sequences and totals. Raw line text is intentionally
omitted from the feature artifact, but line ids, artifact identity/hash, and a
structural-projection identity allow the retained upstream projection to be
reopened. Both projections declare read-only behavior, no event-ledger write,
and no cluster mutation.

## Responsibility and standing determination

The two roads expose one recurring **constitutional ordering constraint**:

```text
occurrence represented and available
  before comparison
  before recurrence
  before consumer-local materiality
```

They do not yet expose one recurring **implementation responsibility**. Their
producers, subjects, representations, scopes, losses, and consumers differ.
The external road's local gap is comparison production over already-addressable
line/region occurrences. The ingress road's local gap is preservation of
invocation occurrences before any comparison can be honest. Documentation
Probe supplies a third, compiled corpus-local owner and cannot be generalized
into either missing owner.

Therefore the “common absence” classification is:

* **competency probing:** Unknown as an owner; neither road establishes a
  universal probe;
* **evidence preservation:** the first concrete absence for ingress, but not
  for external line/region occurrences;
* **recurrence measurement:** the first concrete absent producer for the
  external road, but downstream and premature for ingress; and
* **one constitutional responsibility across both:** unsupported beyond the
  ordering constraint.

No comparison here establishes competency standing. At most, an external-road
PESC comparison could establish a bounded measurement finding. A later,
separately authorized consumer would still need applicable evidence,
currentness, scope, alternatives, loss, Unknowns/conflicts, and its own
sufficiency rule before relying on the finding for any candidate or competency
standing. Comparison availability is not consumer Uptake.

## Smallest honest next inquiry and lawful stop

No implementation recommendation is warranted. The current repository lacks a
complete independent producer -> evidence -> comparison -> consumer road for
either specimen.

The smallest honest next inquiry is narrower than PR 2006's recurrence
question:

```text
Does any current caller, event producer, diagnostic recorder, or projection
independently preserve the occurrence of a BOGE ingress evaluation—rather than
only its content-derived returned value—with occurrence identity, exact ingress
lineage, episode/scope, order or time/currentness, Unknowns, conflicts, and

```

If no such producer exists, stop at evidence preservation. If one exists, only
then inspect its declared P, E, S, and consumer-local C and ask whether its
comparison produces bounded recurrence. Do not infer the road from generic
event machinery, serializers, tests retaining local variables, stable hashes,
Documentation Probe adjacency, or BOGE's refusal vocabulary.

For the external specimen, the correspondingly smallest follow-up question is
only whether an already-active named consumer actually compares retained
structural line/feature occurrences under an explicit P/E/S and bounded C. The
current search found none. Until independent evidence answers either question,
this recovery stops before materiality, pressure, Demand, candidate promotion,
competency establishment, realization, or routing.
