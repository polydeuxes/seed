discriminator. It does **not** report an examination or establishment of common
grammar. Thus it is historical purpose shorthand and misleading overclassification,
but not presently an authority relocation or a semantically consumed false finding.
Payload limits and the addressable artifact expressly refuse that promotion.

## A–B. Exact road and independent acts

For a decoded, non-EOF console line, every real non-test edge is:

```text
run_persistent_operator_console
  -> capture_stdin_material(input_stream)
  -> run_operator_ingress_common_grammar_probe_attempt(
       ledger, workspace_id, session_id, captured_ingress,
       response_input_stream, output_stream)
     -> new attempt_ref
     -> _capture_representation(material_role="initial_ingress")
        -> record raw_material_captured
        -> examine_text_representation
        -> record representation_examined
     -> record ingress_occurred
     -> StateProjector(ledger).project(workspace_id)
        -> replay prefix dispatch in StateProjector.apply
        -> project_operator_ingress_common_grammar_events
        -> form_operator_ingress_addressable_material(event, ledger)
        -> serialize into attempt view[addressable_operator_material]
     -> return attempt view
  -> console discards returned view and repeats
```

The console is the entry caller and process/session loop owner; the runner owns one
generated attempt; `_capture_representation`, the decoder, Event ledger, addressable
material producer, and projector own their narrower acts. The input subject is one
line framed at the available stdin/binary-stream boundary. The caller supplies
workspace and session identity plus captured material, but no purpose identifier,
semantic question, applicable grammar, consumer, or BOGE relation. The Event payloads
carry attempt, role, scope, representation evidence, occurrence-only authority and
meaning Unknown; the projected artifact carries addressability limits, not semantic
purpose. The real final consumer is the attempt-view projector/serializer. Generic
replay can reproduce that view; no production semantic consumer reads it, and the
console discards it. The road then returns quiescently.
