# Bounded Goal Priority Focus Selection Recovery 001

## Governing question

What current constitutional responsibility, if any, selects one established bounded operator goal as the present focus when multiple bounded goals exist, what operator preference or delegated authority does that act require, and how does the repository preserve `priority != eligibility != dependency != present focus` before constructing a `BoundedAdvancementHorizon`?

## Central finding

No current implementation-backed Seed responsibility was recovered that selects one established bounded operator goal as the present focus from multiple established bounded goals before `BoundedAdvancementHorizon` construction. After PR 1948, the live horizon producer directly consumes one supplied `BoundedOperatorGoalEstablishment` plus a supplied present movement boundary, refuses only a refused goal or missing boundary, and explicitly preserves negative authority: it does not select the goal, establish focus, classify needs, judge sufficiency, open inquiry, authorize, record, write the event ledger, or mutate cluster state.

The repository does preserve the distinctions mostly by absence and negative fields rather than by a positive multiple-goal selector. Goal establishment preserves one bounded goal's ingress lineage and standing. Horizon construction preserves one supplied goal identity and boundary. Need-set and advancement-need consideration roads distinguish unordered coexisting need families and need selected-for-consideration, but those are downstream of a horizon and are not a goal-priority or goal-focus selector. Historical goal-orientation inventory and candidate-resolution reports testify that the removed bridge was compatibility-only identity confirmation, not constitutional focus selection.

Classification: **absent** for present bounded-goal focus selection; **evidenced** for one-goal horizon preservation; **partially evidenced** for general consideration-selection grammar; **Unknown** for any current constitutional rule that turns operator ordering, indifference, or delegation into a selected bounded goal.

## 1. Current multiple-goal topology

Recovered topology:

```text
operator material / upstream selection or admission
→ BoundedOperatorGoalEstablishment for one exact bounded goal
→ caller supplies that one bounded goal and a present_movement_boundary
→ establish_bounded_advancement_horizon(...)
→ BoundedAdvancementHorizon for that one goal
→ need projections / GoalAdvancementNeedSet / advancement-need consideration / bounded inquiry frontier
```

What is not currently recovered:

```text
multiple independently established bounded goals
→ constitutionally preserved bounded goal set
→ operator preference / ordering / indifference / delegation artifact
→ eligibility and dependency examination across goal identities
→ priority standing or Unknown
→ present bounded-goal focus selection
→ BoundedAdvancementHorizon
```

The older bridge road was reported as constructible/test-active only and compatibility-only: association, inventory bucketing, visible candidates, caller-supplied testimony, exact identity resolution, then horizon. That report explicitly found no real goal selection or focus establishment in the bridge.

## 9. Direct goal → horizon construction and unproved selection

Current direct handoff most closely matches:

1. **assumes the caller has already lawfully selected the goal** — **partially evidenced/Unknown**, because the producer accepts a single supplied goal without constructing selection evidence.
2. **treats any supplied established/provisional goal as sufficient for horizon construction when boundary exists** — **evidenced**, because only refused goal and missing boundary block the path.
3. **contains another hidden focus-selection witness** — **absent**, because fields and boundary notes deny selection/focus.
4. **is compatibility-only** — **not for horizon preservation**; the old bridge was compatibility-only, while direct horizon preservation is evidenced.
5. **faithful only when exactly one goal exists** — **partially evidenced as a safe reading**, because no multi-goal selector or goal set is preserved; when exactly one goal exists, no unrepresented alternative is being ignored.
6. **remains Unknown** — **yes for selection authority**, because caller-side selection standing is not represented.
